## 四、剩余项与保留原因

1. **主出卷链路静态题：0 条可达。** 删除超纲题后，U5 脱式、U2 简便的静态池为 0；其余无规则单元本来就没有静态条目；填空/应用全部走骨架包。
2. **代码库仍保留 26 条三上旧题。** 原因：旧预览页 `index.html` 仍直接读取 `QUESTIONS`（Tauri 主程序不使用该页）。这 26 条答案正确、知识点属三上，符合“可用但风格老 → 保留并标注来源为旧题库”。若未来下线旧预览页，可把 `QUESTIONS` 的三上部分整体删除，残留即可归零。
3. **旧生成器仍是潜在兜底路径。** 当骨架包抛错或产出 0 时，U1/U4/U5/U6/U7/U8/U9 的填空、U1/U4/U5/U6/U8/U9 的应用会走旧生成器；该路径常规出卷不命中，命中时 `notes` 会写明“骨架不可用，旧…生成器兜底 N 题”。保留原因：旧生成器输出已接入运行时复核（结构 + 答案非空），且备注明示来源，不构成静默混用。
4. **容量补齐路径已无旧题可补。** 计算类配额不足时会尝试 `fallbackUnits`，但相关单元的旧题池已清空或本就不存在；实测混合选 U1+U5（脱式）、U1+U7/U1+U8（口算/脱式）各 60 题，静态兜底均为 0。
