- 归并口径：按公众号归并，同一号出现 ≥2 篇且标题落在“三上/三年级上册”优先，最终保留 19 个候选号。
- 访问验证：`curl` + Chrome 桌面 UA 逐个打开文章（不跟随搜狗跳转页，先解析成 `mp.weixin.qq.com` 直链再访问），判定四件事：
  1. HTTP 200，且不是“环境异常/验证码”拦截页；
  2. 页面存在 `#js_content` 正文容器且能取到文字；
  3. 内容确为三上阅读短文 + 题目（不是纯资料包广告）；
  4. 是否附答案。
- 指标口径：`正文汉字` 是正文容器里的汉字总量（短文 + 题目 + 答案），不等于单篇短文长度；`最长段` 用最长自然段估算短文篇幅。`选择/填空/简答` 是按“A./B.”、“（ ）”、“为什么/怎样/说说”等标记计数，用于判断题型构成，不是精确题数。
- 限流处理：搜狗跳转与微信正文都会对高频访问返回拦截页；遇到时停 3–6 秒重试一次，仍失败就记为“未验证/受限”，不做绕过。
- 链接性质：清单里的链接是微信分享链（带 `src=11&timestamp=...&signature=...`），能直接打开，但签名会随时间失效。建议采集当时就把正文存下来，不要把它当永久书签。
