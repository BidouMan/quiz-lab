## 3. 三档分工落点（本轮三包）

### 3A-U7 马拉松路线 · 应用

- L1：单段路程与换算 —— 千米与米的单次换算、几千米几米合起来、一段路程直接求。
- L2：分段求和或比较 —— 先走一段再走一段求和、两段路线比多少、分段与剩余。
- L3：多段综合或往返 —— 三段合计、往返少走 / 多走，问句方向与算式一致。
- 单位同口径：问米答米、问千米答千米；`ROUTE_SCENES` 32 张，L1/L2/L3 三档 0 重复。

### 3A-U8 数学广场 · 应用

- L1：单点或直接求 —— 正方形周长、三边篱笆、留门、七巧板块数、单独摆图形的根数。
- L2：两步 —— 四边篱笆、靠墙三边、留门、七巧板平均分、连排摆剩几根、找规律相差。
- L3：最值或判断 —— 篱笆长最多、两种靠墙围法省多少、并排拼框少围多少、最多摆几个并剩余。
- 与 U6 周长应用三档句式 0 撞车；几何对象统一写“长方形 / 正方形{item}”，尺寸 3–60 米，避开 U6 厘米池。

### 3A-U9 复习 · 应用

- L1：基础复习 —— 数值收窄，每题仍融合两个知识点（周长 + 单价、年月日 + 乘法、千米 + 加法、周长 + 除法）。
- L2：综合 —— 时刻 + 经过时间、相框周长反求宽、两天路线比较、七巧板平均分。
- L3：提高 —— 数值放大但仍在本册上限内，两年 2 月合计、花坛摆花盆、买彩笔再平均分。
- 红线：U1/U2 口吻只用加减乘，不出现除法；除法只出现在以 U4 为知识点之一的题；三档答案最大 7400。

### 3A-U8 数学广场 · 填空

- L1：单点辨认或直接求 —— 七巧板 7 块 / 5 块三角形、摆 1 个正方形 4 根、正方形周长、三边篱笆、边长差。
- L2：两步 —— 靠墙篱笆（长边 / 宽边 / 留门）、反求长或宽、长方形改正方形、七巧板乘加、照规律第 n 个。
- L3：最值或判断 —— 宽最大 / 长最大、最多摆几个并剩余、四边篱笆反推、两块并排、边长加 1 后比较。
- 与 U6 周长包零撞车：U8 全部改为「一块长方形菜地」+ 米场景；混合卷实测题干 0 / 句式模板 0 撞车。

### 3A-U9 复习 · 填空

- L1：基础复习 —— 平年闰年二月与全年、大月小月、千米与米、正方形周长、整十整百乘除、时刻加经过时间、送还求原。
- L2：两单元混合 —— 年月日 + 时间、周长 + 乘除、单价 + 减法、路程 + 比较、除法 + 余数、平年闰年比较。
- L3：三步或综合判断 —— 两次购买与找回、往返路程、休息扣减与反推、闰年跨年、围两圈、装箱后再加 1 每盒、两个平年合计。
- 范围红线：仅本册已学加减乘、一位数除、周长、年月日、时分、千米与米；U1/U2 口吻 0 处除法与平均分。
