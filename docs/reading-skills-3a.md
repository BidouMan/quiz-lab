# 三年级上册阅读理解考点体系（v1）

用途：统一命题、采集补缺与第三阶段复审的口径。每篇素材在入池后按 `SK1–SK7` 打「可覆盖考点」标签，统计分布后定向补缺，不按随机加量。

| 代码 | 考点 | 一句话判定 | 三上常见问法 |
| --- | --- | --- | --- |
| SK1 | 提取信息 | 答案能在原文直接圈出，不需概括 | 谁、什么时候、在哪里、哪些、画出句子、填表 |
| SK2 | 梳理概括 | 需要合并多处信息，用一句话或按顺序说清 | 主要写了什么、按顺序填一填、概括段意、几件事 |
| SK3 | 词句理解与赏析 | 解释词句意思，或说出表达效果 | 加点词的意思、这句话好在哪里、用了什么修辞 |
| SK4 | 推断与因果 | 原文没有直接答案，需要联系上下文推 | 为什么、原因是什么、预测接下来、如果……会怎样 |
| SK5 | 主旨与情感 | 指向道理、品质、情感、中心 | 告诉我们什么道理、表达了什么感情、人物品质 |
| SK6 | 写法与结构 | 关注文章怎么组织、怎么写 | 开头结尾、总起分述、过渡、详略、照应、写作顺序 |
| SK7 | 非连续性文本 | 表格、清单、通知、目录、海报、多材料组合 | 根据材料判断、看表填空、读目录答题 |

## 命题配比要求

- 每篇至少覆盖 **3 个不同考点**，其中必须含 1 道 **SK2 概括** 或 **SK4 推断**，不能全是 SK1 原文抄找。
- 客观题（选择/填空）与主观题（简答/批注/赏析）都要有；每篇至少 1 道 SK3 或 SK5 的主观题。
- SK6、SK7 属于三上的薄弱项，补缺时优先定向采集：写景/状物文的段落结构、总分结构短文，以及通知/目录/表格类材料。
- 简答题评分点必须能回到原文具体语句，不能只写「言之有理即可」。

## 阶段用法

1. **入池**只卡正文 ≥250 汉字与文体（叙事/写景/说明/非连续），暂不因原题质量拒收。
2. **打标**按现有原题问法给 `skills`；无原题的篇目记 `待命题`，不虚标覆盖。
3. **补缺**看分布：某考点占比明显偏低时，下一批采集定向找对应文体/题型，而不是继续随机加量。
4. **复审**在第三阶段按本表三条硬标准淘汰：考点覆盖 <3、题干只考记忆或抄写、答案无法回溯原文语句。

## 首轮分布（2026-11-08，素材池 406 篇）

- 有原题 375 篇，待命题 31 篇；每篇平均可覆盖 **3.14** 个考点。
- SK1 提取信息 **77.9%**、SK3 词句赏析 **82.1%**（最充足）。
- SK2 梳理概括 **39.2%**、SK4 推断因果 **50.1%**、SK5 主旨情感 **39.5%**（中等）。
- **SK6 写法与结构 11.7%、SK7 非连续文本 13.6%** —— 明显偏少，下一轮定向补：总分/并列结构的写景状物文、通知/目录/表格/多材料组合。
