# 语文阅读理解题库标准作业（SOP）

**适用**：三上语文阅读题库已完成一轮，本文把从选源到出卷的流程固化成可复用作业书。下次做三下、四上或其他年级，按本文执行，只改第 13 节列出的参数，不重新摸索。

**写作口径**：面向下一次执行的人，不写成成果汇报。每条判定标准都要能当场判「是/否」，不写「注意质量」「尽量规范」这类空话。脚本与数据一律给仓库相对路径。

---

## 0. 使用说明

### 0.1 三条铁律

1. **原文只认来源，不认记忆。** 正文必须能回到来源页逐字核对；OCR 只能改回可查证的字，不能按句式补写。编造原文是红线，一次即下架。
2. **两道闸分开跑。** 入库结构闸 `tools/reading-intake/gate.py` 与命题稿质量闸 `tools/reading-intake/quality_gate.py` 管的不是一回事，不能互相替代。
3. **缺口如实报。** 素材不够就少出、留空、写缺口，不用近似文本、重复篇目或其他考点冒充。

### 0.2 统计口径（先分清再报数）

| 口径 | 定义 | 本库当前值（2026-11-09 实测） | 不能和谁相加 |
| --- | --- | --- | --- |
| 素材池 | 已切出、可命题的不同文章 | 406 篇（小学试卷网 191 + 课内 60 + 21世纪教育网 155） | 不能与命题稿、挂载数相加 |
| 命题稿 | 已成型、带 RD 编号与题目 | 268 篇 / 1340 题 | 不能当作素材池总量 |

## 1. 定范围与一票否决

### 1.1 做什么

1. 写死「只做哪个年级、哪一学期、哪类文体」；本库是三年级上册、课外阅读为主、课内片段仅作补充。
2. 把「命中即拒」的条款列成表，采集、切分、命题、挂载四处都按同一张表执行。
3. 每条拒绝都要落到 `downlisted.json` 或 `rejected.jsonl`，写清规则号和一句话原因。

### 1.2 判定标准

| 项目 | 合格 | 一票否决 | 脚本判定 |
| --- | --- | --- | --- |
| 年级/学期 | 三上；标题与来源不含「下册/三年级下」 | 三下、四上及以上课文、升四/二升三卷 | `quality_gate.py` R1；`harvest_21cnjy.py` `TERM_BAD` |
| 正文长度 | 命题稿正文 ≥250 汉字 | <250 汉字 | `quality_gate.py` R2 |
| 素材入池长度 | 结构闸 150–400（课内）/150–600（课外） | <150；>上限只提示不拒收 | `gate.py` `low/high` |
| 采集探测长度 | ≥60 汉字，>1500 标 `tooLong` | <60 多为导航残渣 | `route_probe.py` |
| 文体 | 叙事、写景、说明、童话、寓言、非连续文本 | 文言文、诗歌、知识梳理、句子仿写、试卷前段、答案页 | 人工 + `route_probe` 体裁筛 |
| 课内/课外 | 课外短文优先；课内片段须完整且≥250 | 教材原文片段不足 250、四上及以上课文 | 人工核教材 |
| 非连续文本 | 表格列齐全、材料编号清楚、文字层可读 | 关键信息只在图片、表格缺列/错行 | 人工 + `vision_doc` 结果 |
| 来源 | 可回看、可核对、允许本地教研使用 | 无法回看、正文缺失、只有引流片段 | 人工 |

## 2. 选源与准入探测

### 2.1 做什么

1. 先做路线探测，不直接放量：每个源抓 10–20 页，记录 HTTP 成功率、正文可解析率、带题率、答案可解析率、重复率。
2. 按「可访问 → 可解析 → 篇幅达标 → 题目/答案可用 → 去重通过」五道门逐层统计，算真实产出，不算页面数。
3. 放弃的源必须写原因分类，避免下次重复试。

### 2.2 判定标准

| 门 | 判定 | 不通过的处理 |
| --- | --- | --- |
| 可访问 | HTTP 200，页面不是验证码/登录/环境异常页 | 记录 `status`，换源；不绕反爬 |
| 可解析 | 能稳定切出「标题 + 正文」，正文无导航、广告、答案块、题号行 | 换入口（详情页/移动版）；仍不行则放弃 |
| 篇幅 | 正文 250–700 汉字（21世纪教育网口径）；三上真题中位 311、最长 455 | <250 不入池；>700 除非用户明确要求，否则不入池 |
| 题目/答案 | 原题 3–8 道且答案可按大题号对位 | 正文可用、题目不可用 → 标 `needsQuiz` 转自命题；答案不可对位 → 不猜 |
| 去重 | 精确 sha256 不同；20 字汉窗覆盖率 <0.9 | ≥0.9 拒收；0.5–0.9 人工判同文异文 |
| 范围 | 标题/来源无三下特征 | 拒收 |

## 3. 采集

### 3.1 做什么

1. **串行 + 节流**：同域请求间隔 1.8 秒；单线程；不并发抢跑。
2. **落缓存**：每个 URL 原样存 HTML 到 `tools/reading-intake/work/<批次>/pages/`，后续解析只读缓存，不重复抓。
3. **断点续跑**：`attempts.jsonl` 记录已处理 id；重跑时 `skip` 已处理；`state.json` 记录列表页进度与 `halt`。
4. **撞墙即停**：遇 403/429/验证码/环境异常，写 `halt`，不重试、不换 UA、不绕反爬；人工确认后再 `clear-halt`。
5. **区分页面类型**：列表页只取候选 id/标题；详情页取全文；混排页（整卷多篇）只用于补候选，不直接当单篇入库。

### 3.2 判定标准

| 项目 | 判定 | 脚本实现 |
| --- | --- | --- |
| 请求间隔 | 同域 ≥1.8 秒 | `route_probe.py` `_throttle()` |
| 超时 | 30 秒 | `rp.fetch(..., timeout=30)` |
| 缓存命中 | 本地文件存在且非空即复用 | `harvest_21cnjy.fetch_page()` |
| 断点 | `attempts.jsonl` 已有 `docId` 则跳过；`--force` 才重抓 | `harvest_21cnjy.run()` |
| 列表页到底 | 404 视为到底，继续翻页不 halt | `bulk_harvest.discover_*()` |
| 非 200 | 写 `halt` 并停手 | `bulk_harvest` |
| 详情页空正文 | 先试移动版 `mip.21cnjy.com/P/{id}.html` | `harvest_21cnjy.fetch_page(suffix="-p")` |
| 混排页 | 只抽候选，不直接切单篇 | `bulk_harvest.MIXED` |
| 记录 | 每次请求写状态、耗时、字节数 | `attempts.jsonl` |

### 3.3 列表页 / 详情页 / 混排页

| 类型 | 用途 | 只取什么 | 不要做什么 |
| --- | --- | --- | --- |
| 列表页 | 发现候选 | 标题、详情 URL、页码 | 不要把列表页当正文；不要因列表页 404 就停整站 |
| 详情页 | 取单篇全文 | 标题、正文、题目、答案 | 不要在详情页里再翻下一篇 |
| 混排页 | 补老卷候选 | 候选 id + 标题 | 不要直接把整页当一个 passage；必须回详情页 |

### 3.4 对应脚本

- `tools/reading-intake/route_probe.py`：`fetch()`、`html_to_text()`、正文切分。
- `tools/reading-intake/bulk_harvest.py`：`init/run/report/review/clear-halt`；`state.json`、`candidates.jsonl`、`attempts.jsonl`。
- `tools/reading-intake/harvest_21cnjy.py`：`run --ids a,b,c`、`report`；`passages.jsonl`、`attempts.jsonl`、`rejected.jsonl`。
- `tools/reading-intake/wechat_probe.py`：只做探测，不做批量。

## 4. 清洗与切分

### 4.1 做什么

1. HTML → 文本：去 `script/style/nav/a`、去导航/广告/版权/下载提示，保留答案题号行（`1.C`、`（2）`）。
2. 切出四块：标题、正文、题目、答案；多篇混排按独立标题行/阅读大题头切分。
3. 表格页单独走 `vision_doc`；逐行 OCR 会把表格压成一行，不能直接用。
4. 图片/扫描件走 `intake.py pages → ocr → clean → blocks → locate_with_llm`；模型只输出段号，程序回填原文。
5. 清洗只做「可查证」的修：去题号、去混入的相邻篇/答案碎片、分段、标点全半角统一、OCR 形近字改回原字。**不写原文没有的句子。**

### 4.2 判定标准

| 项目 | 合格 | 不合格 |
| --- | --- | --- |
| 标题 | 与正文一致，2–28 字，无「阅读短文/参考答案/评分标准」等板块名 | 标题是来源注记（「摘编自××网」）、标题与正文不符 |
| 正文 | 单一文章，首尾完整，无题号行、无答案、无相邻篇 | 混入上一篇尾句/下一篇开头、正文是答案页、正文挖空 |
| 题目 | 题干与正文对应；题号连续；题量与原卷一致 | 题号跨篇平铺、题干属于另一篇、题量异常多（>8 多为混入） |
| 答案 | 按大题号→子题号对位；对不上标 `source-missing` | 整卷答案 1–N 平铺直接塞给单篇 |
| 表格 | 每列都有表头、每行都有对应值；行列不错位 | 缺列（如民族列丢失）、日期与区域错行 |
| OCR | Vision revision 2；正文 CER ≥90%；形近字逐字核 | CER <90%、表格被压成一行、②/③、⑤/⑥ 混淆未核 |
| 分段 | 按语义分段，≥3 段 | 整篇一段、按 OCR 行切碎 |
| 来源 | 保留 URL/页面 id/抓取时间 | 只留标题，无法回看 |

### 4.3 允许补全 vs 红线

| 动作 | 允许 | 条件 |
| --- | --- | --- |
| 标点全半角统一、多余空格清理 | ✅ | 不改字义 |
| 去卷面题号、去「阅读短文」前缀 | ✅ | 题号另存结构 |
| 去混入的相邻篇/答案碎片 | ✅ | 切后正文完整、字数仍达标 |
| 按语义重新分段 | ✅ | 不改字序、不增删句 |
| OCR 形近字改回原字 | ✅ | 必须能在另一份完整原文或词典查证；只改回原字，不润色 |
| 用另一份完整原文替换残缺稿 | ✅ | 替换后重新核对标题、正文、题目；旧稿下架 |
| 按句式补写缺失对话/结尾 | ❌ | 红线：这是编造原文 |
| 把答案/题干里的句子补进正文 | ❌ | 红线 |
| 为凑字数加过渡句、加描写 | ❌ | 红线 |
| 改人名、地名、数字让题目成立 | ❌ | 除非有来源可查证 |

**红线案例 RD-637**：原 OCR 稿麻雀答句与结尾缺字，曾按公鸡句式补写「不能抓树枝了」「再也不穿鞋子了」。处理：改用 21世纪教育网课文页《小猫咪穿鞋了》完整原文（381 字），恢复麻雀/大白鹅/大黄狗三问、猫妈妈「好像医生的听诊器」、结尾「再也不想穿鞋子了」，标题同步改为《小猫咪穿鞋了》。**不许保留自造文本。**

### 4.4 表格与 OCR 的硬要求

| 类型 | 做法 | 验收 |
| --- | --- | --- |
| 试卷表格 | `vision_doc` 单页识别（16.8 秒/页），逐行核 | 表头齐全、行列对应、数字/日期不错位 |

## 5. 去重

### 5.1 做什么

1. 先做精确去重：正文去空白后 sha256 相同即重复。
2. 再做近似去重：正文只留汉字，滑 20 字窗口，算候选窗口与全库任一篇的覆盖率。
3. 比对语料必须包含：全部素材池、全部命题稿、本站之前批次、跨年级/跨批次旧稿；不能只比当前批次。
4. 覆盖率高的进入「包含/节选」判定：短篇被长篇完整包含、同一故事不同版本、同一课文不同片段，分别处理。

### 5.2 判定标准

| 判定 | 条件 | 处理 |
| --- | --- | --- |
| 精确重复 | sha256 相同 | 直接拒收 |
| 硬重复 | 20 字汉窗覆盖率 ≥0.9 | 拒收 |
| 同文异文/节选 | 覆盖率 0.5–0.9，或最长连续公共片段 ≥20 字 | 人工判：同故事不同版本可低优先收；同一课文片段不重复收 |
| 包含关系 | 短篇窗口几乎全部被长篇覆盖 | 视为重复；若长篇更完整，可升级已有稿，不新增 |
| 不同标题同故事 | 角色、情节、结局相同，文字重合低 | 人工判同文异文；产品不接受多版本则拒收 |
| 同篇内重复 | 同一篇题干重复 | 必须改题；`quality_gate` 只查同篇题干 |

**当前脚本阈值**：`harvest_21cnjy.py` 用 `SHINGLE = 20`、`DUP_RATE = 0.9`；`docs/reading-audit-2026-11-08.md` 用「覆盖率 ≥50% 判 B1 硬重复」做审计分类。**仓库里没有 0.6 这个阈值**；如果下一轮想用 0.6，必须改脚本并重跑全库，不能只在文档里写。

### 5.3 对应脚本

- `tools/reading-intake/harvest_21cnjy.py`：`shingles()`、`check_dup()`、`corpus_texts()`。
- `tools/reading-intake/cli.py`：本地导出目录的 sha256 + simhash 指纹去重。
- `tools/reading-intake/compare_origin.py`：只做来源对比，不做去重。
- 审计方法：`docs/reading-audit-2026-11-08.md` 第 1.3 节（20 字窗 + 最长连续公共片段）。

## 6. 打标

### 6.1 做什么

1. **逐题**给 SK1–SK7：看这道题要求学生做什么，不看题干里出现了哪个词。
2. **篇级**取逐题并集，不额外加「可能考」的考点。
3. 按正文汉字数与考点判难度；SK6/SK7 一律记难。
4. 为凑覆盖硬加考点是禁止项：某篇没有写法题，就不给 SK6；宁可篇数少，不要标签假。

### 6.2 SK1–SK7 判定

| 代码 | 考点 | 一句话判定 | 三上常见问法 |
| --- | --- | --- | --- |
| SK1 | 提取信息 | 答案能在原文直接圈出，不需概括 | 谁、什么时候、在哪里、哪些、画出句子、填表 |
| SK2 | 梳理概括 | 需要合并多处信息，用一句话或按顺序说清 | 主要写了什么、按顺序填一填、概括段意、几件事 |
| SK3 | 词句理解与赏析 | 解释词句意思，或说出表达效果 | 加点词的意思、这句话好在哪里、用了什么修辞 |
| SK4 | 推断与因果 | 原文没有直接答案，需要联系上下文推 | 为什么、原因是什么、预测接下来、如果……会怎样 |
| SK5 | 主旨与情感 | 指向道理、品质、情感、中心 | 告诉我们什么道理、表达了什么感情、人物品质 |
| SK6 | 写法与结构 | 关注文章怎么组织、怎么写 | 开头结尾、总起分述、过渡、详略、照应、写作顺序 |
| SK7 | 非连续性文本 | 表格、清单、通知、目录、海报、多材料组合 | 根据材料判断、看表填空、读目录答题 |

### 6.3 判定标准

| 项目 | 合格 | 不合格 |
| --- | --- | --- |
| 逐题 skill | 每题一个合法 SK 代码，写在 `questions[].skill` | 缺失、写中文全称以外的自造词、一题贴多个 |
| 考点数 | 每篇 ≥3 类 | <3 类 |
| 必含 | 至少 1 道 SK2 或 SK4 | 全是 SK1 |
| 主观题 | 至少 1 道 SK3 或 SK5 的简答 | 无赏析/体会类主观题 |
| 篇级 skills | 逐题并集，升序 | 为凑覆盖加未考题 |
| SK6 | 题目必须真的考结构/写法，且答案不依赖术语 | 只问「这样写好不好」、答案必须是「总分总」等术语 |
| SK7 | 材料必须是非连续/多材料结构，列齐全 | 把连续说明文贴 SK7 |
| 难度 | 见 6.4 | 用难度标签凑分布 |

### 6.4 难度判定（与脚本一致）

`quality_gate.py` `difficulty_of()`：

| 条件 | 难度 |
| --- | --- |
| 正文 >550 汉字，或含 SK6/SK7 | 难（C） |
| 正文 350–550 汉字 | 中（B） |
| 正文 <350 汉字 | 易（A） |

目标分布：易 30%、中 50%、难 20%（±5 个百分点）。**实际不等于目标**：当前 312 篇为易 91（29.2%）、中 129（41.3%）、难 92（29.5%），难超上限、中低于下限。原因是 SK6/SK7 一律记难、长文偏多；下一轮要么调整口径，要么补中档篇目，不能假装达标。

### 6.5 对应脚本

- `tools/reading-intake/tag_skills.py`：素材池按原题关键词打标，输出 `data/reading-catalog/skills-tags.jsonl`；只用于池子分布，不替代命题稿逐题标注。
- `tools/reading-intake/quality_gate.py`：`SKILL_MAP`、`SKILL_INFER`、`difficulty_of()`；R11 要求每题有合法 skill 字段。
- `tools/reading-intake/compare_origin.py`：按 skill 统计 A/B/C 三组占比。
- `src/data/chinese/readings/tags.ts`：44 篇精选的逐题补标（`skills`、`questionSkills`、`difficulty`）。

## 7. 命题三条路径

### 7.1 做什么

1. 先判原题可用性，再决定走哪条路径：原题复用（L1）、修补（L2）、重写题组（L3）、自命题（L4）。
2. 路径一旦确定，只做该路径允许的动作；修补不改正文，自命题不编原文。
3. 所有题目必须满足：题干可回原文、答案/评分点可回溯、干扰项同域、无超纲术语、难度可解释。

### 7.2 判定标准：路径

| 路径 | 适用条件 | 必须保留 | 允许改动 | 不允许 |
| --- | --- | --- | --- | --- |
| L1 原题复用 | 原题 3–5 道，`quality_gate` 全过 | 题干、选项、答案、考查角度、题序 | 只做平台题型转换（如问答→四选一），并记录 | 改正文、改答案、删题 |
| L2 修补 | 只差锚点/评分点、干扰项长度比、缺 1 道主观题、个别选择题引句不在原文 | 原题干与考查角度 | 补原文锚点、补评分点、改干扰项、补 1 题 | 换文章、换考点、重写整组 |
| L3 重写题组 | 题量 <3、全是填空无主观、选项缺失/重复、答案与题目错位、混入相邻篇 | 文章与可用的原题信息 | 重写该题组 | 改正文、编答案 |
| L4 自命题 | 素材没有可用原题，或原题全部不可用 | 文章原文 | 按结构模板新命 3–5 题 | 编原文、贴术语、出常识题 |

`quality_gate` 失败规则 → 路径映射（来自 `docs/quality-plan-3a.md` 4.2）：

| 失败规则 | 路径 |
| --- | --- |
| R9、R10、R5 的「无主观题但有选择题」、R8 的「explain 无引句」 | L2 |
| R3、R6、R8 的选项数/重复/答案越界、全部填空无主观 | L3 |
| 无任何题目 | L4 |
| R1/R2 | 直接下架，不进 L1–L4 |

### 7.3 结构模板（按真题校准）

三上真题 14 篇：156–455 字，中位 311 字，每篇 3–7 题（4–5 题为主），客观题约 75%，主观题 1–2 题。据此定 4 题模板：

| 位置 | 考法 | 题型 | 必须做到 |
| --- | --- | --- | --- |
| 1 | 定位提取 | 选择/填空 | 答案在原文一句内可找 |
| 2 | 词句理解或画线找句 | 客观 | 用「从文中找出/用横线画出」这类真题动作 |
| 3 | 表格/填空梳理 | 填空 | 至少一空要概括或换词，不能全是照抄 |
| 4 | 推断或体会 | 简答 | 问「为什么/懂得了什么」，不问「你同意吗」 |

当前成稿统一 5 题：在 4 题模板上再加 1 题，优先补 SK4 推断或 SK5 主旨；**不要用第 5 题重复第 1 题的考点**。

### 7.4 命题硬约束

| 项目 | 标准 |
| --- | --- |
| 题量 | 3–5 题；当前成稿统一 5 题 |
| 题型配比 | 客观（选择/填空）≥2，主观（简答）≥1；按真题约 3:1 控制 |
| 考点 | ≥3 类，含 SK2 或 SK4，至少 1 道 SK3/SK5 主观 |
| 填空 | `（ ）` 数量 = `blanks` 数量；每个答案逐字在原文 |
| 选择 | 4 个互异非空选项；答案下标 0–3；`explain` 含 ≥6 汉字原文引句 |
| 简答 | 2–3 条评分点；至少 2 条含 ≥4 汉字原文锚点；必须有成句参考答案（R13） |
| 干扰项 | 同质同域；长度比 ≤2.0；无「以上都对/无法判断」；无玩笑/自贬项 |
| 正确项位置 | 同篇不连续 3 题相同；全库按篇均衡（`balance_options.py`） |
| 术语 | 三年级不要求「总分总/借景抒情/动静结合/点面结合」等术语；必须考结构时，用直白问法，答案不是术语 |
| 提问动词 | 至少 1 道「摘录/画出/找出」类检索题；少用「请联系上下文说说你的理解」 |
| 开放题 | 只有一条道理+文中依据；评分点写可判定的要点，不写「言之有理即可」 |
| 长文 | >600 字可以保留，但题目必须覆盖全文关键转折，并在 `review` 注明「超真题篇幅，题目已覆盖全文」 |

## 8. 机器闸门

### 8.1 做什么

1. 每批命题稿落盘后立刻跑 `quality_gate.py`，不要等攒够 50 篇。
2. 逐条读失败规则，按 7.2 映射到 L2/L3/L4；R1/R2 直接下架。
3. `quality-gate.jsonl` 是挂载依据；`export_mounted.py` 只导出 pass 且未下架的稿。
4. 记住：**pass ≠ 质量过关**。脚本只判结构、字符串、可回溯性，判不了语义。

### 8.2 判定标准：规则表（与 `quality_gate.py` 一致）

| 规则 | 判什么 | 阈值/条件 | 失败动作 |
| --- | --- | --- | --- |
| R1 范围 | 来源/标题含「下册/三年级下」 | 命中即 fail | 下架 |
| R2 字数 | 正文汉字数 | <250 | 下架 |
| R3 题量 | 题目数 | 不在 3–5 | L3 |
| R4 考点 | 不同 SK 数；是否含 SK2/SK4；是否有 SK3/SK5 主观 | <3 类；无 SK2/SK4；无该类主观（SK4 问「体会/感受/心情/品质」时脚本也按 SK5 口径计入） | L3/L2 |
| R5 题型 | 客观题、主观题数量 | 客观 <2；主观 <1 | L2/L3 |
| R6 抄写/记忆 | 纯抄写/纯记忆题数；是否全 SK1 | ≥2 道；全部 SK1 | L3 |
| R7 填空 | 占位与答案数；答案是否在正文 | 不相等；答案找不到 | L2 |
| R8 选择 | 4 个互异非空选项；答案下标；explain 引句 | 非 4 项/重复/越界；无 ≥6 汉字原文引句 | L2/L3 |
| R9 简答 | 评分点 2–3 条；≥2 条可回溯锚点 | 条数不符；锚点 <2 | L2 |
| R10 干扰项 | 长度比；凑数项；同篇正确项连续 3 题相同 | >2.0；含「以上都对/无法判断」；连续 3 题同位置 | L2 |
| R11 skill 字段 | 每题 skill 是否合法 | 缺失/非法 | L2 |
| R12 难度 | 按字数与 SK 粗分易/中/难 | 只记录，不 fail | 人工确认 |
| R13 主观题答案 | 简答题是否有成句参考答案 | 为空 | L2 |

> R13 是脚本后来加的，`docs/quality-plan-3a.md` 的 T1 正文没有这一条。以脚本为准：简答题必须有参考答案，不能只给评分点。

### 8.3 判定标准：机器判不了的盲区

| 盲区 | 脚本为什么判不了 | 必须人看什么 |
| --- | --- | --- |
| R9 锚点语义 | 只看评分点里有没有 ≥4 汉字原文片段，不看该句是否支撑答案 | 引句是否真的回答了题干 |
| R6 纯抄写/记忆 | 只看「读音/默写/摘录/画出」等关键词 | 题目是否只是搬运原文，没有概括/解释/比较 |
| R10 干扰项同域 | 只看长度比与凑数词 | 四个选项是否同一类事物、是否一望而知 |
| R12 难度 | 按字数与 SK 粗分 | 实际认知负荷：跨句、跨段、因果链 |
| 超纲术语 | 规则里没有术语词表 | 「总分总/借景抒情/动静结合」等是否超出三年级 |
| 正确项位置均衡 | 只拦同篇连续 3 题相同 | 全库 A/B/C/D 是否均衡；是否「都选 A」可拿分 |
| 题干模板化 | 只查同篇题干重复 | 跨篇是否同一句式换文不换题 |
| 答案语义正确 | 只查答案在原文逐字出现 | 答案是否真的答对了题，而非只是「文中有这个词」 |
| 正文是否被改写/编造 | 只能查引文命中，不能判断原文 | 逐句对照来源页；OCR 缺口是否按句式补写 |
| 来源真实性/版权 | 不检查 | 能否回看、是否允许本地使用 |
| 常识可答 | 不检查 | 不读原文能否凭生活常识答对 |
| 选项长度暗示 | 只拦 >2.0 | 1.9 仍可能暗示；选项是否等长/等结构 |
| 表格行列对应 | 不检查 | 日期、区域、数字是否错行 |
| 范围 | R1 只查标题/来源 | 正文是否四上及以上课文 |
| 题量与正文匹配 | 不检查 | 长文是否只考前两段 |
| 跨卷重复 | 单卷纯函数，无跨卷状态 | 连续出卷是否重复同一篇 |

- `tools/reading-intake/quality_gate.py`：R1–R13 全量闸门；`--dry-run` 只看统计，`--ids` 只跑指定稿，`--write-downlist` 同时写下架清单。

## 9. 人工复核

### 9.1 做什么

1. 机器过闸后，按「孩子可能被误判」的风险排序，不按编号顺序抽。
2. 单题必须指出**具体缺陷**（哪一句、哪个选项、为什么），不写「可以」「注意质量」。
3. 盲评：先遮住答案、解析、评分点、skill、来源，独立做题并写答案；再对照原答案，记录分歧。
4. 人机结论不一致时，以人工证据为准；不能证明答案唯一的题，改题或下架降级。

### 9.2 判定标准：抽样与排序

| 项目 | 标准 |
| --- | --- |
| 每批抽样量 | 20 篇或 10%（取较大者）；不足 20 篇全查 |
| 优先排序 | ① 开放简答/多问复合；② 逻辑链长（表格/多材料）；③ 答案依赖反推的说明文；④ 含术语；⑤ 表格缺列；⑥ 顺序题两可；⑦ 情感题可答点宽 |
| 本轮清单 | `data/reading-catalog/REVIEW-PRIORITY.md` 32 篇，前 20 位优先 |
| 覆盖面 | `quality-gate.jsonl` 的 `needs_human_review` 268/268 为 true；32 篇是风险排序子集，不是「只有 32 篇要看」 |

### 9.3 判定标准：评分卡（单篇）

| 维度 | 判定 | 不合格示例 |
| --- | --- | --- |
| 正文 | 与来源逐字一致；无混入/缺段/编造 | 按句式补写结尾（RD-637 旧稿） |
| 题目对应 | 每题都能在正文找到依据 | 题干问第二段，正文只有一段（szx-0169） |
| 答案正确 | 答案不仅「在原文」，而且真的答题 | 引句在文中，但答非所问 |
| 评分点 | 2–3 条；每条有原文锚点；能区分答一半/答全 | 两条都是抽象道理（RD-356 旧稿） |
| 干扰项 | 同域、等长、无玩笑项；正确答案位置不固定 | RD-311 第 2 题长度比 2.7 |
| 超纲 | 无术语、无四五年级写法赏析 | RD-615「反衬」 |
| 抄写/记忆 | 不是纯搬运；至少一空要概括 | RD-381 四题全填空、量词题偏记忆 |
| 难度 | 与字数、跨句/跨段需求一致 | 说明文强问「作者情感」，依据偏弱（RD-529） |

**通过条件**：8 个维度全部「合格」，且没有 P0（编造原文、答案错误、范围错误）。任一 P0 → 下架或重做；两个及以上 P1 → 返修后再复核。

### 9.4 盲评流程

1. 导出「正文 + 题干 + 选项」的干净版，删掉 `answer`、`explain`、`scoring`、`skill`、`origin`、`sources`。
2. 复核人独立做题，写下自己的答案与依据句。
3. 对照原答案：一致 → 记录「一致」；不一致 → 写「我的答案/原答案/依据句/判断」。
4. 第二复核人只看分歧题，不看出题人身份。
5. 分歧处理表：

| 情况 | 处理 |
| --- | --- |
| 原答案有明确原文依据，复核人漏看 | 维持，记录理由 |
| 原答案依据不足，复核人答案成立 | 改答案或改题；不能两个都算对 |
| 两种答案都成立 | 改题干限定条件，或降为开放题并写宽评口径 |
| 题目本身超出三年级 | 换题；不为保标签留题 |
| 正文有问题 | 整篇下架，不修补题目 |

- `tools/reading-intake/review_batch.py`：按编号列下一批待修题，标「缺答案/术语/模板题干」。
- `tools/reading-intake/quality_gate.py`：`human_review_flags`、`needs_human_review`、`human-review-samples.jsonl`。

## 10. 挂载与出卷

### 10.1 做什么

1. 只导出白名单字段，不把命题过程元数据带进前端。
2. 主题不合并：非连续、童话、记事保持独立；考点保留 SK 代码；难度保留 A/B/C。
3. 出卷支持按主题、考点、难度组合筛选；组内 OR，主题×考点取交集。
4. 素材不足时按实际数量出卷，明确写缺口，不用其他篇目填充。

### 10.2 判定标准：字段白名单

`export_mounted.py` 输出 `ChineseReading`：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✅ | `RD-\d{3}`，唯一 |
| `title` | ✅ | 非空 |
| `theme` | ✅ | 九类：写人/写景/写事/状物/寓言/科普/非连续/童话/记事 |
| `paragraphs` | ✅ | 非空，≥3 段 |
| `status` | ✅ | 正式 `verified`；待修 `pending` |
| `sources` | ✅ | `label` + `locator`，有 URL 则保留 |
| `questions` | ✅ | 3–5 题；每题带 `skill` |
| `skills` | ✅ | 篇级并集，排序去重 |
| `difficulty` | ✅ | `A`/`B`/`C` |
| `review` | ✅ | 复核记录，非空 |

### 12.2 机器先筛 / 必须人看

| 只能机器做 | 只能人做 |
| --- | --- |
| 字数、题量、题型、选项数、答案下标、占位符数量 | 正文是否被改写/编造 |
| 填空答案是否逐字在正文 | 引句是否真的支撑答案 |
| explain/评分点是否有原文片段 | 干扰项是否同域、是否荒谬 |
| 长度比、凑数项、连续 3 题同位置 | 是否超纲术语、是否常识可答 |
| skill 字段是否合法 | skill 标签是否贴错（为凑覆盖） |
| 难度粗分 | 难度是否符合实际认知负荷 |
| 同篇题干重复 | 跨篇模板化、跨卷重复 |
| 下架/待修过滤 | 来源真实性、版权、表格行列对应 |

### 12.3 一页纸顺序

1. 看范围：年级、正文长度、来源。
2. 看正文：是否完整、是否混入、是否编造。
3. 逐题看 SK：这题到底让学生做什么。
4. 逐题找依据句：填空/选择/简答各按 R7/R8/R9 核。
5. 逐题看干扰项：同域、等长、无玩笑项。
6. 逐题看术语与常识：三年级能不能答。
7. 看难度：字数 + 跨句/跨段。
8. 看整篇：题量、题型配比、考点覆盖、是否只考前两段。
9. 写结论：合格/返修/下架 + 具体缺陷 + 位置 + 建议。
10. 盲评分歧：按 9.4 处理。

### 13.3 头 20 篇必须先校准

**为什么**：换年级后，字数、题型、答案深度、OCR 版式、来源重复率都会变；直接放量会把同一类错误复制 200 遍。头 20 篇是「校准批」，不是「正式批」。

**校准批要产出的数**：

| 指标 | 记录方式 | 通过线（建议） |
| --- | --- | --- |
| 采集成功率 | 可取页/尝试页 | ≥60%；低于 40% 换源 |
| 正文可解析率 | 切出完整正文/可取页 | ≥70% |
| 去重淘汰率 | 重复/切出 | <50%；高于 60% 说明该源已被采空 |
| 结构闸通过率 | `gate.py` pass/20 | ≥80% |
| 命题稿闸通过率 | `quality_gate.py` pass/20 | ≥60%；低于 40% 先改流程，不放量 |
| 人工复核合格率 | 评分卡全合格/抽 10 | ≥70% |
| 篇幅分布 | 20 篇汉字数 | 落在真题区间内；中位数接近真题中位 |
| 题量分布 | 3/4/5 题各多少 | 与真题 4–5 题为主一致 |
| 题型配比 | 客观:主观 | 约 3:1，偏差不超过 10 个百分点 |
| SK 覆盖 | 20 篇并集 | 至少覆盖 SK1–SK5；SK6/SK7 有真实篇目才收 |
| 单篇人工工时 | 分钟/篇 | 记录实测；超过 25 分钟先降源复杂度 |
| 失败类型 | 逐篇写原因 | 与本文第 14 节对照；出现新失败模式先补规则 |

**停/继续规则**：

- 20 篇里出现 1 次编造原文 → 停，先修流程与红线检查，再重做校准批。
- 命题稿闸通过率 <40% → 停，先改命题模板与评分点写法。
- 重复率 >60% → 换源或换入口，不要继续扫。
- SK6/SK7 连续 10 篇找不到真实材料 → 如实报「该类素材不可得」，不用连续文本冒充。
- 人工复核合格率 <60% → 停，先做 10 篇盲评，找出系统性偏差。

## 附：一页纸执行顺序

1. 定范围（第 1 节）→ 写一票否决表。
2. 探源（第 2 节）→ 20 条小样，算真实产出。
3. 采集（第 3 节）→ 缓存、断点、撞墙即停。
4. 清洗切分（第 4 节）→ 标题/正文/题/答案四块；表格单独走 `vision_doc`；不编原文。
5. 去重（第 5 节）→ sha256 + 20 字窗 0.9；0.5–0.9 人工判。
6. 打标（第 6 节）→ 逐题 SK；篇级并集；难度按脚本。
7. 命题（第 7 节）→ L1/L2/L3/L4；4 题模板；5 题成稿；评分点带锚点。
8. 机器闸门（第 8 节）→ `quality_gate.py`；按 R 规则修。
9. 人工复核（第 9 节）→ 20 篇/10%；盲评；具体缺陷。
10. 挂载出卷（第 10 节）→ 白名单字段；主题/考点/难度筛选；缺口如实报。
11. 记录提交（第 11 节）→ 每批一提交；四类记录；测试通过。
12. 单题核对（第 12 节）→ 逐题过表；机器先筛，人看语义。
13. 换年级（第 13 节）→ 先改参数与路径；头 20 篇校准后再放量。
