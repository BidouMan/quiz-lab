# 语文三上练习方案（0.7.0）

> 状态：讨论稿。本文只做方案与查证，不包含任何代码改动；`src/app/*`、`src/quiz/*`、`typst/*` 均未修改。
> 查证时间：2026-11-06。凡是没能查到一手/可靠来源的内容，正文直接标注「待核实」，不做推测性补全。

## 0. 结论摘要

1. **上海 2026 学年三年级上册语文，用的是人教社「统编教材·五·四学制版」，不是沪教版语文。** 上海只在数学等学科保留沪教版；语文的配套练习册、写字册在上海 2026 年秋季教学用书目录里都署名「人教社」，配套「（五·四学制）·语文（三年级上册）」。
2. **三年级上册是 2025 年秋季启用的修订版教材，2026-2027 学年三年级继续使用这一版。** 依据是教育部「2025 年覆盖小学一、二、三年级」的替换计划，以及人教社 2025 年 10 月发布的修订要点文章（明确写「2025 年秋季开始使用的三年级上册统编小学语文教材」）。2026 年秋季是否有新版重印/微调，**待核实**。
3. **结构：8 个单元、26 课。** 6 个普通阅读单元 + 第 3 单元阅读策略单元 + 第 5 单元习作单元；另有口语交际 4 次、习作 8 次、语文园地 7 个、快乐读书吧 1 个。篇目清单见 §1.2，来源为 2025 秋五四制三上电子课本目录，并与人教版修订说明中的「新增/替换篇目」逐条对上。
4. **题型分三档**：字词类（注音、看拼音写词语、多音字、形近字、词语搭配、近反义词、词语积累、古诗默写）可以规则化生成、答案可复核；句子类与课文内容填空是半规则；课内阅读、课外阅读、写话必须靠题库或人工/AI，且写话无法自动复核。
5. **排版不是「换个模板」的量级**：田字格、四线三格、阅读短文版式、答题横线都要新增模板能力。实测当前随包字体能显示带调拼音（会回退到西文字体），但注音排版的字号/基线需要专门处理。
6. **建议路线：先做「规则化字词句」（路线 A），课内阅读作为第二期（路线 B），课外阅读与写话最后再说（路线 C）。** 详见 §5。

## 2. 题型可行性

先约定一件事：本产品的「复核」指**能生成与题面一致的参考答案，供家长人工核对**，不是自动判分。语文的主观题即使有答案，也不能承诺机器判对。

| 题型 | 需要素材 | 答案是否唯一、可复核 | 能否规则化生成 | 建议 |
|---|---|---|---|---|
| 生字注音（看字写拼音） | 识字表 + 逐字拼音；多音字需词境 | 基本唯一；多音字离开词境不唯一 | **可以**（字→拼音直接映射；多音字必须绑定词语） | 第一批做 |
| 看拼音写词语 | 词语表 + 逐词拼音 | 唯一 | **可以**（拼音→词语反向映射，需去重、避免同音词歧义） | 第一批做 |
| 多音字（给词选音/注音） | 多音字表 + 组词 | 唯一（按词定音） | **半规则**（必须依赖人工整理的多音字词表，不能靠通用拼音库自动推） | 第一批做，但先建小表 |
| 形近字组词 | 形近字分组 + 允许的组词集合 | **不唯一**（一个字形近字可组多个词） | 半规则：能出题，答案要做「可接受答案集」 | 第二批；答案集是主要工作量 |
| 词语搭配（量词/动词+名词等） | 固定搭配表 | 多数唯一，少数多解 | 半规则：搭配表可人工整理成「一对一」才可规则化 | 第二批 |
| 近义词/反义词 | 词表 + 近反义关系 | **多解**（近义词常有多个） | 只能题库/人工；规则生成容易出争议答案 | 谨慎，靠人工审 |
| 词语积累（成语、日积月累） | 语文园地「日积月累」+ 成语表 | 默写唯一 | **可以**（按教材固定内容出默写/补全） | 第一批做，限定在教材内 |
| 句子类（扩写、改写、关联词、标点） | 例句 + 参考答案 | 多解，评分靠人工 | 弱规则；可作为「示例+参考」但不做自动答案 | 第三批或不做 |
| 古诗文默写与理解 | 古诗原文（公版）+ 教材要求 | 默写唯一；理解多解 | 默写可规则化；理解必须题库 | 默写第一批，理解第二批 |
| 课文内容填空 | 课文原文（或节选） | 「按原文填空」唯一；「按理解填空」多解 | 半规则；必须依赖课文原文录入 | 第二批 |
| 课内阅读 | 课文原文/节选 + 人工命题与答案 | 有参考答案，但需人工命题 | **不能规则生成**，必须题库 | 第二批（路线 B） |
| 课外短文阅读 | 课外短文 + 人工命题与答案 | 同上，且素材版权是硬约束 | 不能规则生成；短文可公版/AI 起草+人工审 | 第三批（路线 C） |
| 写话/习作 | 题目 + 要求 + 参考范文（可选） | **无法自动复核** | 不可生成「标准答案」 | 只给题目与提示，不评分 |

结论：

- **能稳定规则化的只有「教材内字词 + 默写」**，因为它们背后是封闭集合（250 识字 + 写字表 + 词语表 + 日积月累）。
- 一旦进入「组词、近反义、句子、阅读、写话」，答案空间打开，必须有题库或人工整理的可接受答案集；否则会出现「答案看着对、家长一查教材不对」的质量事故。

## 3. 素材来源

| 素材 | 服务的题型 | 从哪来 | 谁提供 | 录入量（粗估） | 版权注意 |
|---|---|---|---|---|---|
| 识字表（250 字 + 拼音 + 所属课） | 生字注音、看拼音写词语 | 教材附录；可用公开教辅交叉核对 | 用户提供纸质教材/拍照；或由用户录入后我方校对 | 250 行 ×（字/拼音/课）≈ 750 格 | 生字表属教材编排，**不要内置分发**；随用户本地数据走 |
| 写字表（字数待核实） | 田字格书写、看拼音写词语 | 同上 | 同上 | 待核实 | 同上 |
| 词语表（条目数待核实） | 看拼音写词语、词语搭配 | 同上 | 同上 | 约 300–400 条（待核实） | 同上 |
| 多音字词表 | 多音字 | 教材 + 教辅整理 | **必须人工整理** | 三上约 20–40 个多音字（待核实） | 自建表可规避版权 |
| 形近字分组 + 组词答案集 | 形近字组词 | 教辅/教研整理 | 人工 | 每组 2–4 字、每字 2–3 词，约 60–120 组（估） | 组词可自建；不要抄教辅整页 |
| 固定搭配表 | 词语搭配 | 教材词语表 + 人工 | 人工 | 100–200 条（估） | 自建 |
| 课文原文（26 课） | 课文内容填空、课内阅读 | 教材 | 用户提供；**不建议我方内置** | 全册约 2–3 万字，录入+校对重 | 教材文本版权归人教社；整篇复制进产品风险高 |
| 古诗原文 | 古诗默写 | 公版古籍 | 公开来源可核 | 8–10 首（待核实） | 原文公版；**注释/译文/赏析有版权，不能抄** |
| 语文园地「日积月累」 | 词语积累、默写 | 教材 | 用户提供 | 7 个园地，量小 | 同上，教材编排 |
| 习作要求 | 写话题目 | 教材 | 用户提供 | 8 条 | 可改写表述，避免逐字复制 |
| 课外短文 | 课外阅读 | 公版短文 / 授权 / AI 起草 | 用户拍板 | 每篇 300–500 字，10–20 篇 | **版权硬约束**：公版或授权；AI 起草需人工审读 |
| 拼音库（多音字读音兜底） | 注音辅助 | 开源拼音库（如 pinyin-pro 类） | 技术侧引入 | — | 开源许可需核对；读音口径必须以教材/词典为准，不能直接信库 |

录入工作量的现实判断：

- **字词三表是可控的**：250 字规模，一次录入 + 两轮校对即可；真正耗时的是「多音字按词定音」和「形近字可接受答案集」。
- **课文原文是大头**：26 课全文录入、分段、标点校对，工作量明显高于字词表；如果只做「按原文填空」，可以只录**目标段落**而不是全篇，成本能砍一半以上。
- **阅读题不是录入问题，是命题问题**：每篇 3–5 题 + 答案 + 干扰项，需要懂教学的人出，AI 只能起草。

版权口径建议：

1. 产品若只服务**单个家庭本地使用**，风险相对低，但仍不应把教材全文随安装包分发。
2. 若要对外发布，教材课文、教辅题目、教材插图都不能内置；应改为「用户导入自己的教材内容」或只用公版/自建素材。
3. 古诗原文可用；但教材里的注释、译文、赏析文字有独立版权，不能复制。
4. 课外短文优先公版（作者去世满 50 年）或明确授权；AI 生成短文需人工审读事实与价值观。

## 4. 排版差异（数学 vs 语文）

当前数学卷面基线（`typst/paper.typ`）：A4、左右 12.7mm、上 19mm/下 16mm、正文 14pt、行空 5.6mm、可两栏排口算。语文化的差异如下：

| 维度 | 数学现状 | 语文需求 | Typst 可行性 | 需要补的能力 |
|---|---|---|---|---|
| 田字格 | 无 | 写字练习/看拼音写词语的书写格 | **可以**：用 `line`/`rect`/`grid` 画方格 + 十字虚线 | 新构件：单字格、连续田字格行；格宽随字号联动 |
| 四线三格 | 无 | 拼音书写练习 | **可以**：四条横线分组，按行重复 | 新构件：拼音行；与汉字行对齐的基线 |
| 拼音注音 | 无 | 题面注音、答案页拼音 | **部分可以**：Typst 原生 ruby 仍在路线图（未内置）；社区包 `rubby`/`auto-pinyin` 可做，但需 vendor 与审阅 | 方案一：数据层预置拼音，模板按字定位（可控但代码多）；方案二：引入社区包（快但引入依赖风险）。**建议方案一** |
| 拼音字体 | 随包 Noto Serif CJK SC 子集 | 带调拼音（āáǎà…ǖǘǚǜ） | 实测：当前字体**不含**这些码位，会回退到 New Computer Modern 西文字体，能显示、但字形风格不统一 | 需补一套含拼音声调的字体，或接受西文回退；字号/基线要单独调 |
| 阅读短文 | 无 | 300–500 字短文 + 题目 + 答题区 | **可以**：整栏或 `columns` 窄栏；字号 12–14pt 可配 | 新模板：短文块、题号、答题横线；控制「短文不跨页」 |
| 答题横线 | 有 `blank()`（下划线） | 词语/句子/阅读简答的长短线 | **可以**，已有构件可复用 | 按题型区分线长（词 2–3 字宽、句整行、阅读 2–3 行） |
| 每页容量 | 14pt、行空 5.6mm，约 46 行/页 | 字词类密度高；阅读类密度低 | 可以算，但需按题型实测 | 需要为每类题型定「每页上限」，不能沿用数学的题目数配额 |
| 卷面结构 | 口算/填空/竖式/解决问题 | 一、字词 / 二、句子 / 三、阅读 / 四、写话 | **可以**：大题 + 小题两级编号 | 新模板的编号体系；答案页与卷面一一对应 |
| 页脚/答案页 | 页码 + 共几页 | 语文同样需要；答案页建议独立 | 可以 | 答案页模板 |

每页容量的粗估（按 14pt、行空 5.6mm、可用高度约 262mm）：

- 纯文字行：约 44–46 行/页；按每行约 36–37 个汉字（可用宽 184.6mm），约 **1600 字/页** 的理论上限。
- 看拼音写词语：每题占「拼音行 + 词语行 + 间隔」，约 14–16 题/页。
- 田字格书写：单格约 10–12mm，每行约 14–16 格，一页约 12–16 行，约 **200 格/页**。
- 课内阅读：一篇 300–400 字短文 + 4 题 + 答题区，约 **1 篇/页**；短文更长时要允许跨页或缩字号。
- 以上是版面估算，**不是实测值**；最终要以实际模板跑出的页数为准。

一个必须提前定的产品问题：**语文卷是「练习卷」还是「测试卷」**。练习卷可以带田字格、注音、留白大；测试卷更接近考试排版、留白小。两种卷面容量和模板是两套。

## 5. 可选路线

> 工作量是「粗估人日」，只用于比较量级，不含设计评审、联调、反复改版；实际以排期为准。

### 路线 A：只做规则化字词句（推荐先做）

**范围**：生字注音、看拼音写词语、多音字、形近字组词、词语搭配、近反义词（限教材内固定对）、词语积累/日积月累、古诗默写、简单的课文原句填空。

- **能力边界**：全部基于封闭素材（识字表/写字表/词语表/日积月累/古诗原文），答案可生成；不涉及整篇阅读、不涉及写话。
- **工作量粗估**：8–12 人日。其中素材整理 3–4 天、田字格/四线三格模板 2–3 天、出题与答案校验 3–5 天。
- **质量风险**：低到中。主要风险是多音字读音口径、形近字组词答案集不全、同音词反向映射歧义。
- **建议**：**先做**。它能验证「语文卷面 + 素材数据层 + 生成链路」是否成立，且不碰数学逻辑。

### 路线 B：A + 课内阅读与古诗理解（第二期）

**范围**：在 A 基础上增加课内阅读（每单元 1–2 篇课文/节选，3–5 题）、古诗理解、课文内容填空。

- **能力边界**：需要课文原文或节选入库；需要人工命题与答案；生成器只负责选题、排版、组卷，不负责「编题」。
- **工作量粗估**：A 的 8–12 人日 + 课内阅读题库 6–10 人日（8 个单元，每单元 1–2 篇，命题+审题）+ 阅读版式 2–3 天。
- **质量风险**：中。风险在「题目与课文对应关系」「答案表述与教材口径」；一旦课文改版，题库要跟着改。
- **建议**：**第二期做**。先做 1–2 个单元的样板，确认版式与命题成本，再铺满 8 个单元。

### 路线 C：全量（+ 课外阅读 + 写话）

**范围**：在 B 基础上增加课外短文阅读、写话/习作。

- **能力边界**：课外短文需要版权来源或 AI 起草 + 人工审；写话只能给题目、要求、提示，**不能给标准答案、不能自动评分**。
- **工作量粗估**：B 的工作量 + 课外短文 10–20 篇（选文/授权/命题/审读，8–15 人日）+ 写话模块 3–5 人日。
- **质量风险**：高。版权是硬风险；AI 起草的短文与题目容易「看着像、细看不对」；写话无法复核，家长预期要提前管理。
- **建议**：**以后再说**。除非明确要做「整卷模拟」，否则收益不如把 A/B 的字词与课内阅读做扎实。

### 路线对比

| | A 字词句 | B A+课内阅读 | C 全量 |
|---|---|---|---|
| 能覆盖的卷面 | 字词卷、默写卷 | 字词 + 课内阅读卷 | 接近完整单元卷 |
| 素材依赖 | 三表 + 日积月累 + 古诗 | 再加课文原文/节选 + 题库 | 再加课外短文版权 + 写话 |
| 答案可复核 | 高 | 中（阅读题有参考答案） | 低（写话无标准答案） |
| 版权风险 | 低（用户本地素材） | 中（课文原文） | 高（课外短文） |
| 建议 | 先做 | 第二期 | 暂缓 |

## 6. 与现有架构的衔接（只设计，不改代码）

现状：`src/app/subjects.ts` 已经用 `units / types / presets` 给语文留了占位结构；数学的出题、配额、复核在 `src/quiz/*`，排版在 `typst/paper.typ`。语文接入时**不要复用数学的出题器与 paperBuilder**，也不要把语文数据塞进数学题型枚举。

建议的数据形状（与占位结构同构，只是把占位换成真实字段）：

```ts
// 仅示意，不在本次改动范围内
interface ChineseUnit {
  unitId: string          // 对应教材单元，如 'u1'
  unitName: string        // 单元名（需与教材核对后录入）
  lessons: { lessonId: string; title: string; type: '精读' | '略读' }[]
}

interface ChineseType {
  typeId: string          // 如 'pinyin-write' | 'polyphone' | 'cloze-text'
  label: string
  grade: 'A' | 'B' | 'C'  // 难度/是否入库
}

interface ChinesePreset {
  id: string
  name: string
  total: number
  mix: Record<string, number> // typeId -> 题量
}
```

- 素材建议独立成 `data/chinese/3A/*.json`（字词表、多音字表、课文节选、题库），与数学 `data/` 分离，避免影响数学测试。
- 生成链路建议：`chineseBuilder`（选题/配额）→ `typst/paper-chinese.typ`（新模板）→ 同一套 Tauri 编译调用。数学的 `paperBuilder`/`typst/paper.typ` 保持不动。
- 语文 UI 已具备 `ChinesePanel.vue` 的骨架，接入时替换占位数据即可，不需要重做信息架构。

## 7. 需要用户拍板的问题

1. **教材口径**：确认「上海 2026 学年三上语文 = 人教社统编五·四学制修订版」这一口径；如果孩子学校实际发的是别的版本/校本材料，请以实物为准并告知。
2. **素材由谁提供**：三表、课文原文、语文园地内容，是由你拍照/录入提供，还是希望我方按公开资料整理？（后者版权风险更高）
3. **产品定位**：只做本地家庭自用，还是准备对外分发？这直接决定能不能内置教材原文。
4. **第一批范围**：是否同意先做路线 A（字词句），课内阅读放第二期？
5. **卷面类型**：语文卷做「练习卷」（带田字格、注音、大留白）还是「测试卷」（接近考试版式）？还是两套都要？
6. **阅读题**：是否允许使用课外短文？如果允许，来源限定为公版、授权，还是接受 AI 起草+人工审？
7. **写话**：要不要进卷？如果进，只给题目/提示、不评分，是否可以接受？
8. **答案页**：语文卷是否需要独立答案页（家长核对用）？答案页是否要带拼音/田字格？
9. **多音字与组词口径**：多音字按「教材出现的读音」还是「常用读音全列」？形近字组词允许多少个可接受答案？
10. **每页容量与题量**：语文一页希望放多少题（例如字词 20–30 题/页）？是否允许跨页？
