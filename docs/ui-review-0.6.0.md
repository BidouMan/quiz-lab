# 0.6.0 界面体检报告（现状基线）

- 日期：2026-11-05
- 范围：`src/app/DesktopApp.vue`、`ParamsPanel.vue`、`PdfPreview.vue`、`types.ts`、`wording.ts`、`typeCapacity.ts`、`paperBuilder.ts`
- 方法：读源码 + 用本地 vite 起真实界面（模拟后端返回现成样张 PDF，不产出新题）截取 1240×860 实际窗口与 1240×1900 整栏两档，见 [现状截图](ui-current-0.5.0.png)
- 约束：本批不改 `src/app/*.vue`，不改版本号，不打 tag

截图里能直接看到的现状：左栏 292px 塞了 7 个分组（年级/单元/难度/题型与题量/数量与版面/排版引擎/设置备份），860 高度下只能看到前 3 组；12 个题型全列出来，其中 9 个未勾选却仍显示题量（竖式 6、比大小 4、判断题 4……），而"总题数 34"只算已勾选的 3 类；出卷按钮在右上角，和左栏参数区脱节。

严重度口径：**P0 挡路**（家长做不下去或会做错）、**P1 明显别扭**（能用但要猜）、**P2 打磨**。
