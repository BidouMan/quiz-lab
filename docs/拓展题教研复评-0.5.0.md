## 2. 最该先改的 Top 3

### Top 1｜摆长方形：题面锁死 + 留白加到 8 行（P0）

**问题**

1. `每根算一条边` 自相矛盾：长方形只有 4 条边，24 根小棒不可能“每根算一条边”。本意应是“每根算 1 厘米/一个长度单位”。
2. `摆` 没有锁死是“沿边围一圈”还是“铺满”。P12 铺满得到 12×1、6×2、4×3；沿边围得到 5×1、4×2、3×3。P24 铺满只有 4 种，沿边围有 6 种，**答案会差 2 种**。
3. 长宽顺序没锁。答案按“长 ≥ 宽”只算一种；孩子若把 5×1 和 1×5 算两种，P12 得 5 种、P24 得 11 种，而答案分别是 3 种和 6 种。
4. 6 行 51mm 不够。一组一行 + 算式 + 答，P20/P22 需 7 行、P24 需 8 行；20/22/24 占 3/7 = **42.9%** 的题。

**证据（抽样原文）**

- 现题干：`用24根同样长的小棒摆长方形（每根算一条边，正方形也算长方形）。一共有几种摆法？列出每种摆法的长和宽。`
- 现答案：`共6种：长11宽1、长10宽2、长9宽3、长8宽4、长7宽5、长6宽6`
- 若按铺满读：P24 是 `24×1、12×2、8×3、6×4`，只有 4 种；若按顺序不同算两种：P24 是 11 种。两者都不是答案的 6 种。
- 留白：`workLines: 6`（`src/quiz/advanced.ts:1148`）→ `6 × 8.5mm = 51mm`（`typst/paper.typ:291-296`）。P24 的 6 组 + `24÷2=12` + 答句，孩子一组一行时正好写满 6 行，没有算式和答句的位置。样张第 6 页可看到该题下方只剩约 51mm。

**具体改法**

- 题干改为：
  `用${perimeter}根同样长的小棒沿边围成一个长方形（每根算1厘米，正方形也算长方形），长不短于宽。一共有几种围法？写出每种的长和宽。`
  - “沿边围成”锁死周长模型；
  - “每根算1厘米”锁死单位；
  - “长不短于宽”锁死顺序，正方形只算一种；
  - 删掉“每根算一条边”。
- 答案改为带单位、正方形单独称呼：
  `共6种：长11厘米、宽1厘米；长10厘米、宽2厘米；长9厘米、宽3厘米；长8厘米、宽4厘米；长7厘米、宽5厘米；长6厘米、宽6厘米（正方形，边长6厘米）`
- `workLines` 6 → 8（68mm）。
- 步骤 1 的 `（根）` 改为 `（厘米）`，避免“长+宽=12根”这种半截单位。
- 测试同步：
  - `tests/advanced.test.ts:367` 的 `workLines: 6` → 8；
  - `tests/advanced.test.ts:371-399` 增加“题干必须含‘沿边’‘长不短于宽’‘每根算1厘米’”的断言。

**影响范围**

- `src/quiz/advanced.ts:1146-1203`（`sample` 1146、`workLines` 1148、`stem` 1151、`build` 1152-1185、`recompute` 1186-1195）。

### Top 2｜剪拼：剩下部分的“长/宽”倒置（P0）

**问题**

`build` 把剩下部分固定写成“长 = 原长 − 宽、宽 = 原宽”。当 `原长 − 宽 < 原宽` 时，短边被写成了“长”，长边被写成了“宽”。小学教材里“长”是较长的那条边，这会直接教错术语。

**证据（抽样原文）**

- 3000 题中 **1948 题（64.9%）** 满足 `原长 − 宽 < 原宽`。
- 反例：`一张长13厘米、宽8厘米的长方形纸，从一端剪下一个最大的正方形。剩下图形的周长是多少厘米？`
  步骤原文：`……从一端剪下后，剩下部分长5厘米、宽8厘米`。剩下部分是 5×8，长应是 8、宽应是 5。
- 再如 `长11、宽8` → `长3、宽8`；`长9、宽8` → `长1、宽8`。
- 答案不受影响（仍是 `2×原长`），错的是解法步骤的术语，但老师会按步骤讲。

**具体改法**

- `src/quiz/advanced.ts:855` 改为先取长短边：
  ```ts
  const longSide = Math.max(rest, w)
  const shortSide = Math.min(rest, w)
  text: `……剩下部分长${longSide}厘米、宽${shortSide}厘米`
  ```
- 或改成不带长宽术语的写法：`剩下部分的两条边分别是${rest}厘米和${w}厘米`，再写 `(${rest}+${w})×2`。前者更贴教材，推荐前者。
- 在 `tests/advanced.test.ts:318-336` 增加断言：扫描 1000 题，步骤里的“长”必须 ≥“宽”。

**影响范围**

- `src/quiz/advanced.ts:855`（1 行 + 2 个局部变量）。
- `tests/advanced.test.ts:318-336`。
- 答案、`recompute`、留白都不变。

## 3. 其余问题（按严重度）

### 3.1 P0｜经过时间：同小时步骤用绝对分钟 + 答案 3 种写法

- **问题**：同一小时内的分支直接拿“从 0 点起的总分钟数”相减，不是教材写法；答案对 ≥60 分钟同时给“1时X分（X分）”，但题干没交代格式。
- **证据**：
  - `丽丽7时开始读书，7时40分读完。她读书用了多长时间？` → 步骤原文 `开始和结束都在7时内，直接算分钟`、`460-420=40（分）`。孩子应写 `40-0=40` 或 `7时40分-7时=40分`，不会写 460/420。
  - 同小时分支 209/3000 = **7.0%**。
  - 答案 `1时45分（105分）` 这类双写法 2337/3000 = **77.9%**；另外 `1小时45分`、只写 `105分` 也是对的，但答案串没有“小时”写法，题干也没说“用几时几分表示”。
- **改法**：
  - 同小时步骤改为 `em - sm`（同小时内 `em > sm`），`text` 用 `结束时刻 - 开始时刻`，例如 `40-0=40（分）`，不要用 `460-420`。
  - 答案保留双写法，并在判分说明写清“写 `105分` 或 `1时45分` 均对；`1小时45分` 也接受”。若坚持单一格式，题干加“（用几时几分表示）”，但这会把只写分钟判错，不建议。
- **影响**：`src/quiz/advanced.ts:484-490`（同小时分支）、`118-132`（`elapsedAnswer`）；测试补一条“同小时步骤不得出现 ≥100 的绝对分钟相减”。

### 3.2 P1｜租船：题干 56 字 + 31.5% 的策略前提失效

- **问题 1（长度）**：题干字符串 56 字（含数字/标点；上一轮记 57）。可压到 50 字，不丢“不能超载”“怎样最省”“最少多少元”。
- **压缩原文（50 字）**：
  `18人去划船。大船限乘6人，租金30元；小船限乘4人，租金24元。不能超载，怎样租最省？最少多少元？`
  砍掉：`有`、两处`每条`、`要`；保留：租金、限乘、不能超载、怎样最省、最少多少元。版面仍是 2 行，省的是阅读量，不是行数。
- **问题 2（前提）**：`dRentPlan` 对两种船的租金独立随机，**946/3000 = 31.5%** 的题大船人均反而更贵。此时“大船人均便宜、但要比较空位”这个策略点不存在，最优通常直接全租小船（该子样本 74.1% 是全小船）。
- **证据原文**：
  `有15人去划船。大船限乘6人，每条租金37元；小船限乘4人，每条租金19元。不能超载，怎样租最省？最少要多少元？`
  答案 `只租小船4条，最少76元`；大船 37/6≈6.17 元/人，小船 19/4=4.75 元/人。
- **改法**：
  - 题干按上面 50 字版本（`src/quiz/advanced.ts:1028` 的 `sample` 同步）。
  - `draw` 增加前提：`bigCost * smallCap < smallCost * bigCap`（大船人均更便宜），不满足就重抽；或放到 `invariant`。
  - 强制后仍有约 30 种/千级组合；在“大船人均更便宜”子样本里，全大船 51.1%、混租 46.7%、全小船 2.2%，混租比例够，策略点回来。
- **影响**：`src/quiz/advanced.ts:1010-1018`（成本与重抽）、`1028/1033`（题干）；保留 `workLines: 8`（方案表 3–5 行 + 答，够写）。测试加“大船人均更贵必须被拒”。

### 3.3 P1｜周期：`○△○□` 的答案 48.3% 是 ○

- **问题**：5 种周期串里有 4 种是 3–4 个不同符号，唯独 `○△○□` 中 ○ 出现两次；孩子看得到周期串，直接猜 ○ 就有一半概率。题干也没有“写出算式”。
- **证据**：
  - `○△○□`：773 题里答案 ○ 373 次 = **48.3%**；`△○□` 34.8%；`红黄蓝` 35.6%；`ABCD` 26.6%；`红黄蓝绿` 27.5%。
  - 原文：`按“○△○□……”这样的顺序重复排列，第41个图形是什么？` → `○`；`第43个` → 也是 `○`。
- **改法**：
  - 题干加 `（写出算式和答句）`，与星期几一致；3 行仍够：`41÷4=10……1`、`第1个是○`、`答`。
  - 若要把概率压到 ≤35%，把 `○△○□` 换成 `○△□☆`；保留该串则接受 48.3%，靠“写算式”让老师看见过程。两者选一，建议先加算式、暂不改串，保留这个“同符号出现两次”的难点。
  - 顺带把 `ABCD`（英文字母）换成图形串（如 `☆○△□`），避免三上数学卷出现跨学科的字母周期。
- **影响**：`src/quiz/advanced.ts:207-213`（patterns）、`229`（stem）；`tests/advanced.test.ts:401-410` 把“写算式”断言扩展到 cycle。
