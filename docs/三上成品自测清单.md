- 日期：2026-11-04

## 1. 接入方式

| 项 | 行为 |
| --- | --- |
| 题目来源优先级 | 骨架包（单元 + 题型 + 难度有组合）→ 旧生成器（`word.ts` / `fill.ts`）→ 旧静态题库 |
| 映射键 | `3A-U1..U9 \| tiankong/word \| L1/L2/L3`，由 `skeletonSource.ts` 解析成 combo |
| 兜底标记 | `Availability.source` 取 `skeleton/rule/legacy/static`，参数面板题型旁显示「骨架包 / 规则库 / 旧生成器 / 静态题库」 |
| 出卷备注 | 走旧生成器或静态题库时，结果区 `notes` 写明“哪个单元、兜底几题、为什么” |
| 统计字段 | `BuildStats.skeleton / legacy / fallback`，摘要显示“骨架 X · 旧生成器 Y · 静态兜底 Z” |
| 单元列表 | 只列 8 个已建包单元：U1、U2、U4、U5、U6、U7、U8、U9（U3 图形单元不进入列表） |
| 默认题量 | `recommendedCount`：L1=20、L2=16、L3=12；纯填空 30；纯应用 L2=8、L3=6 |
| 排版 | 仍走原 Typst 链路（组版、答案页、PDF 预览、打印、保存），未改 `paper.typ` |

## 5. 已知缺口

1. **U3 图形单元未建包**：填空/应用不可生成，参数面板不列出；图形题仅剩静态示例。
2. **U7/U8 无计算题**：只能出填空和应用；想要计算题需换单元。
3. **U5/U6 递等式只有静态旧题**：可出但池子很小，题量设大时会出现“题量不足”，不是生成器。
4. **U2 简便运算走旧静态题库**：三上是否保留该题型需教研确认；当前会以「静态题库」标记出现。
5. **单包上限 30 题**：一个单元选 30 题以上会截断/不足；跨单元混合不受影响。
6. **旧生成器仅在无骨架组合时启用**：三上 16 个组合全覆盖，正常界面不会触发；三下配置会被钳回三上。
7. **静态题库兜底容量有限**：混合卷若把多个“仅静态”题型同时选满，可能短缺，界面会显示不足原因。

## 7. 还不能直接给孩子用的理由

1. **图形单元缺位**：U3 没有骨架包，整册的图形/几何覆盖不完整；若孩子正好学到图形单元，这份成品接不上。
2. **静态兜底题未逐题教研审核**：U2 简便运算、U5/U6 递等式仍是旧题库，题量少且未按新口径复核，可能出现口径或难度不匹配。
3. **应用层没有运行时复核**：骨架包在离线验收中做过独立复核，但 `buildPaper` 不调用 `verifyPaper`；若要直接发给学生，建议先在应用层补一道运行时答案校验。
4. **真机 UI 只验到参数面板**：本轮四份卷走的是应用同一 `buildPaper + typst` 链路并全部 PASS；Tauri 窗口内的点击出卷仍未做自动化回归，发布前需人工点一遍预览/打印/保存。
5. **跨卷记忆依赖本地文件**：`.quizlab/gen-memory.json` 缺失或被清空时会重新出现旧题，分发前要固定记忆文件。

结论：作为**家长/老师辅助出卷工具**已可用，四份样卷排版全部 PASS；作为**直接发给学生的成品**，建议先补 U3 图形包与旧题库审核，再宣布全册可用。
