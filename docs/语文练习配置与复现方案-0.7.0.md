## 0. 结论先行

1. **默认设置就按复习节奏出题，用户不需要每天调参数。** 出卷方式沿用数学：自定义题型 + 题量；但语文多两个约束维度——**目标时长**和**训练模式**。默认值直接产出「到期复习为主、变式呈现、15 分钟以内」的卷。
2. **语文的重复判定键是「素材ID + 考点标签」，不是「题」。** 同一素材换考点标签视为不同题，允许且推荐复现；同素材同考点在 **7 天冷却期**内跳过。另设「连续 3 份卷不出现同一题面」作为同一天多卷的兜底。
3. **知识点分三层：知识点（KP）→ 考点标签（skill）→ 题面（surface）。** 一个「字」是一个 KP，注音/看拼音/形近字/多音字是 4 个考点标签；每个标签下的具体语境题是题面。调度状态记在 KP 上，去重检查「素材ID + 考点标签」，题面做兜底。
4. **现有数据能支撑 127 个知识点：字 49、词 12、诗句 12、句式 22、阅读篇目 24、习作 8。** 但字词只覆盖第 1–2 单元（第 1–4 课），第 3–8 单元字词为 0；课内阅读为 0；错别字/字义/选词/成语/名言/课文填空全缺。
5. **必须先改数据层，否则算法跑不起来。** 三个硬缺口：① `ChineseWord` 没有拼音，看拼音写词语只能靠脚本硬编码；② 没有语境词表，注音只能抽单字，违反「不机械抽单字字卡」；③ 形近字、多音字不在 `src/data` 里，6 组写在脚本里。阅读还缺 97 道题的「方法点」标签。
6. **日常卷不排习作。** 习作做成 8 个「单元习作包」，每 2 周 1 次，走「写—评—改」，与日常出卷完全分离。
7. **家长只做「会 / 不会 / 未看」三选一，不做批改、不打分。** 全对时一次点击即可；不核对就留空，算法自动退化为「按曝光与时间轮转」，不假装孩子已掌握。
8. **不判分的题不进正确率。** 扩写、仿写、阅读简答、习作只统计「面批完成度 / 达标 / 待改」，单独展示。
9. **库存不够不静默降级。** 生成前摘要必须写清「要 20、可出 12、差 8、原因是什么、可选哪三条路」。
10. **训练模式统一为三种：日常巩固 / 错题回炉 / 单元综合。** 日常巩固默认「当前单元 60% / 旧知 40%」，下分字词、句子、古诗、阅读四个专项；错题回炉只取错字/难字；单元综合按单元覆盖。三者共用一套选卷器，只有配额和窗口不同。
11. **推荐分 8 个阶段落地（S0–S7）：** 前 6 个是主线——知识点索引 → 素材补口 → 调度器 → 选卷器 → 配置界面 → 反馈闭环；习作包（S6）与题库扩容（S7）随后，详见 §9。

现有句式考点可归成 **22 个知识点**：病句 4 类（成分残缺/搭配不当/语序颠倒/重复啰嗦）、关联词 8 种关系、标点 7 个规则家族（26 条原始 rule 归并）、扩写 1、仿写 2（比喻/拟人）。

### 1.2 单元覆盖的真相

`availableTypes` 给 8 个单元都声明了题型，但实际有数据的只有：

| 单元 | 字 | 词 | 诗 | 习作 | 能否出单元综合（字词+古诗） |
|---|---:|---:|---:|---|---|
| 第一单元 | 38 | 12 | 0 | 1 | 能（仅字词） |
| 第二单元 | 11 | 0 | 3 首 | 1 | 能（字词+古诗） |
| 第三～六、八单元 | 0 | 0 | 0 | 1 | **不能**（只有习作） |
| 第七单元 | 0 | 0 | 3 首 | 1 | 只能出古诗 |

**【已定】接 UI 前必须废弃 `availableTypes` 作为可用性来源，改为从实际知识点索引计算。** 否则会出现「界面上有、点进去没有」的落差；`题库体检`已把这条列为接 UI 前必须改。

### 1.3 本方案的三条硬原则

- **复习的是知识点，不是题面。** 同一批字词可以反复练，但每次换考点标签、换语境；同素材同考点 7 天内不重复，原题面另做 3 份卷兜底。
- **默认只做加法，不做替代。** 缺什么就提示什么，不拿别的题型顶替，避免「看起来 20 题、实际少 5 题」。
- **日常练习与诊断卷分开。** 日常 15–20 分钟、以复习为主；诊断卷按单元覆盖，允许 19–29 分钟，每周最多 1 次。

## 2. 知识点模型（数据层）

### 2.1 三层结构

```
知识点 KP（调度与掌握度记在这里）
  └─ 考点标签 skill（同一知识点的不同问法，决定题型与判分方式）
       └─ 题面 surface（这一道具体题的题干指纹、素材ID 与答案）
```

**例子：字「坡」（假设语境词已入库）**

| 层 | 内容 |
|---|---|
| KP（调度单位） | `char:3A-U1-L1:xiezi:坡`（内容键 `char:坡`） |
| 考点标签 | `char.zhuyin` / `char.kanpinyin` / `char.xingjin` / `char.duoyin` … |
| 题面 | 注音：`山坡（ ）`，素材ID `charctx:山坡`；看拼音：`shān pō → ____`，素材ID `word:山坡`；形近字：`坡 / 波 / 破` 组词 |
| 重复判定 | `素材ID + 考点标签`，例 `charctx:山坡` + `char.zhuyin`；7 天内不再出 |

**关键区别：** 「坡」是调度单位，`山坡（ ）` 是素材，`注音` 是考点标签。同一素材换考点（如「山坡」考注音 vs 考看拼音写词）算不同题，允许复现；同一素材同一考点 7 天内只出一次。

### 2.2 字段定义

```ts
// 建议新增 src/data/chinese/knowledge.ts，以下为类型草案
export type KpKind = 'char' | 'word' | 'poemline' | 'pattern' | 'reading' | 'writing'

export interface KpSurface {
  surfaceId: string          // 题面指纹，例：word:洁白:pinyin / RD-02:q3 / GL-10
  materialId: string         // 素材ID：这道题考的是哪条素材
  skillId: string            // 考点标签ID：这条素材被怎么考
  prompt: string             // 题干（或题干引用）
  answer: string | string[]  // 唯一答案或合法答案集
  /** 阅读/句式引用原题库条目时，指向原 id */
  sourceItemId?: string
}

/** 重复判定键：素材ID + 考点标签；冷却期 7 天（自然日） */
export const repeatKey = (s: KpSurface) => `${s.materialId}|${s.skillId}`

export interface KpVariant {
  variantId: string          // = skillId，考点标签，例：char.zhuyin / poem.buchong-front
  label: string              // 界面名，例：给加点字注音
  typeId: ChineseTaskType    // 归到哪个题型
  level: ChineseLevel        // 该考点标签的难度 A/B/C
  judging: 'unique' | 'enum' | 'rubric'
  autoJudge: boolean         // 是否「答案可机判」（不等于现在有判分引擎）
  surfaces: KpSurface[]
}

export interface KnowledgePoint {
  kpId: string               // 调度与掌握单位，例：char:3A-U1-L1:xiezi:坡
  kind: KpKind
  contentKey: string         // 同卷去重键，例：char:坡 / word:洁白 / poem:山行:1
  unitIds: string[]          // ['3A-U1']
  lessonId?: string          // 出处课文，用于卷面标注
  level: ChineseLevel        // 知识点基础难度
  hardDefault: boolean       // 多音字、形近易混、阅读推断等
  variants: KpVariant[]
}
```

| 字段 | 作用 | 取值口径 |
|---|---|---|
| `kpId` | 调度与状态主键 | 用课次 + 表名 + 内容，**不用数组下标**；教材改版时只迁内容，不迁状态 |
| `contentKey` | 同卷去重 | 字/词/诗句/句式/阅读篇/习作单元各自一套；不用 `kpId` 是因为同一字可能出现在不同课 |
| `materialId` | 跨卷冷却主键之一 | 字用语境词、词用词条、诗句用行、句式用原题 id、阅读用篇 id、习作用 `XZ-xx` |
| `skillId` | 跨卷冷却主键之一 | 同一素材的不同问法；同一素材允许多个 skill 并存 |
| `level` | 难度筛选 | A 基础 / B 标准 / C 挑战，沿用 `ChineseLevel` |
| `hardDefault` | 难字优先 | 多音字、形近易混、阅读推断默认 true；其余 false |
| `judging` | 判定方式 | `unique` 唯一；`enum` 枚举合法写法；`rubric` 评分点面批 |
| `autoJudge` | 是否可机判 | **只表示数据结构上可判**；当前 `src/` 没有判分引擎，v1 仍由家长核对 |
| `lessonId` | 课文出处 | 字/词/诗句/习作能绑；句式与阅读是通用素材，留空，不硬编 |

### 2.3 标识规则

| 类别 | `kpId`（调度单位） | `contentKey`（同卷去重） | 素材ID（示例） | 考点标签（示例） | 冷却键示例 |
|---|---|---|---|---|---|
| 字 | `char:3A-U1-L1:xiezi:坡` | `char:坡` | `charctx:山坡` | `char.zhuyin` | `charctx:山坡` + `char.zhuyin` |
| 词 | `word:3A-U1-L1:洁白` | `word:洁白` | `word:洁白` | `word.kanpinyin` | `word:洁白` + `word.kanpinyin` |
| 诗句 | `poem:3A-U2-L4:山行:1` | `poem:山行:1` | `poem:山行:1` | `poem.buchong-front` / `-back` / `poem.moxie` | `poem:山行:1` + `poem.buchong-front` |
| 句式 | `pattern:guanlian:因果` | `pattern:guanlian:因果` | `sentence:GL-10` | `pattern.guanlian:因果` | `sentence:GL-10` + `pattern.guanlian:因果` |
| 阅读 | `reading:RD-02` | `reading:RD-02` | `reading:RD-02` | `reading.fill:找信息` | `reading:RD-02` + `reading.fill:找信息` |
| 习作 | `writing:3A-U6` | `writing:3A-U6` | `writing:XZ-06` | `writing.package` | `writing:XZ-06` + `writing.package` |

**去重规则：**

- 同一份卷：`kpId` 唯一、`contentKey` 唯一。
- 跨卷冷却：同一 `素材ID + 考点标签`（`repeatKey`）在 **7 天自然日**内不再出现；同一素材换考点标签**允许且推荐**（这是「变式复现」的执行口径）。
- 题面兜底：同一 `surfaceId` 在最近 3 份卷内不出现（阅读 8 份），防止同一天出两份卷绕过冷却。
- 例外 1（阅读题组）：一篇短文的 3–5 个小题共享 `contentKey`，**允许同卷出现**，因为它们是同一材料的连续任务；但一篇短文每卷最多 1 次。
- 例外 2（整首默写）：按「行」记 KP，整首默写占 2 个行 KP、按 1 题计时。
- 例外 3（字词联动）：同一词拆出的「字」考点每卷最多取 1 个，防止一个词被拆成 3 个考点反复考。
- 冷却与到期冲突时：到期日到了但冷却未过，顺延到冷却结束；这是唯一允许「到期题晚几天出现」的情况。

### 2.4 现有数据如何映射

| 现有结构 | 映射为 KP | 复用字段 | 需要补什么 |
|---|---|---|---|
| `ChineseChar`（识字/写字） | `char:课次:表:字` | `char`、`pinyin`、`table`、`status`、`sources` | 形近字分组、多音字读音集、语境词/句 |
| `ChineseWord` | `word:课次:词` | `word`、`kind`、`sources` | **`pinyin`（当前缺失）**、搭配、近反义、错别字 |
| `ChinesePoem.lines` | 每行一个 `poemline` | `lines`、`sources` | 无（题面由行文本拆前半/后半） |
| `ChineseSentenceItem` | 按 `kind + subkind/relation/rule/mode` 归 KP | `id`、`level`、`judging`、`answerKind`、`answers`、`rubric` | 标点 26 条 rule 归成 7 个家族；其余可派生 |
| `ChineseReading` | 每篇 1 个 KP | `id`、`theme`、`questions` | **每题的 `skill` 标签（97 条）** |
| `ChineseWritingPrompt` | 每单元 1 个 KP | `unitId`、`scoring`、`requirements` | 无 |

**素材ID落点：** 字/词/诗句直接用内容；句式/阅读用原题 id（如 `GL-10`、`RD-02:q3`）；习作用 `XZ-06`。这样冷却日志可以直接引用现有题库 id，不需要另造编号。

**课文出处落点：** KP 的 `lessonId` 来自 `curriculum.ts` 的课次；卷面只对字/词/诗句/习作显示「第 X 课《课名》」。句式是通用能力、阅读按主题，硬绑课文会造假出处，所以不绑。

### 2.6 判定方式与「自动判分」口径

| 考点标签 | 判定 | 可机判 | v1 实际 |
|---|---|---|---|
| 看拼音写词语、注音、多音字、古诗补全/默写 | `unique` | 是 | 家长对答案页核对 |
| 形近字组词、词语搭配、近反义、关联词、标点、病句可枚举改法 | `enum` | 是（列表内） | 家长核对；列表外同义写法可能判错，界面提示「意思通顺也算对」 |
| 扩写、仿写、阅读简答、习作、病句成分残缺 10 条 | `rubric` | 否 | 家长按评分点勾「达标/待改」 |

**必须说清楚：** `autoJudge` 只决定「答案页是否按唯一答案展示」「未来能否接判分引擎」。**v1 不做自动判分**，调度用的「会/不会」来自家长核对，不是机器判分。错误率统计同理：v1 是「核对正确率」，不是「机器判分正确率」。

### 3.1 维度与默认值

| 范围（单元） | **默认勾选第一、二单元**（当前唯一有字词素材的单元）；第七单元只有古诗，需在「积累」组手动勾选 | 8 个单元多选、全册 | 不写死单元号；同时指定「当前单元」，默认取所选范围中编号最大的有素材单元（当前为第二单元） |

**【已定】范围只作用于字词、古诗、习作。** 句子库 184 条、阅读 24 篇没有单元归属（句式是通用能力、阅读按主题），所以「第二单元」不会把句子题筛成第二单元题；界面要在范围区标注「句子、阅读为全册通用」。硬按单元切句子会造成「选了第二单元却出病句」的困惑。

**【待定】「当前单元」用于 60/40 滚动。** 系统没有教学进度日历，所以当前单元由用户在范围区手选；默认取所选范围中编号最大的有素材单元（当前为第二单元）。不按真实日期猜进度，避免假期/请假造成错位。

### 3.2 难度比例

| 选择 | A 基础 | B 标准 | C 易错/挑战 |
|---|---:|---:|---:|
| 基础 A | 90% | 10% | 0 |
| 标准 B（默认） | **70%** | **25%** | **5%** |
| 挑战 C | 30% | 45% | 25% |

**说明：** 70/25/5 是**巩固型经验默认值，不是官方标准**，可按孩子实际调整。5% C 档在 20 题卷里约 1 题，用于「易错字/多音字/难度拔高」，不宜更多。

### 3.3 三种训练模式

## 4. 选卷规则（核心）

### 4.1 约束优先级（从硬到软）

1. **用户指定的题型与题量**（硬）。
2. **同一份卷内 `kpId` / `contentKey` 唯一**（硬；阅读题组、整首默写按 §2.3 例外处理）。
3. **跨卷冷却**：同一 `素材ID + 考点标签` 在 **7 天自然日**内不得出现；同素材换考点标签允许且推荐。题面兜底：同一 `surfaceId` 最近 3 份卷不出现（阅读 8 份）。
4. **到期优先、同 KP 换考点标签**（软，题型配额会压缩它，但不允许完全饿死）。
5. **配额（到期/新/低曝光）**（软，库存不足时让位）。
6. **滚动比例（当前单元 60 / 旧知 40）**（软，只作用于到期以外的剩余槽位）。
7. **目标时长**（软，用户坚持题量时只警告，不截断）。

### 4.2 候选池与动态配比

| 池 | 定义 | 排序 |
|---|---|---|
| **到期复习** | `dueDate ≤ 今天`、`mastery < 2`、未退役 | 逾期天数降序 → 难字/上次不会优先 → mastery 升序 → 曝光次数升序 |
| **新知识点** | `exposures = 0` | 用户选中单元顺序 → 课次 → 难度升序 |
| **低曝光** | 已出现过、未到期、未掌握 | 曝光次数升序 → 上次出现日期升序 → 难度升序 |
| **提前复习**（兜底） | 未到期但离到期最近 | 到期日期升序；卷面标注「提前」 |

**配额（每卷）：**

| 训练模式 | 到期上限 | 新增上限 | 低曝光 | 说明 |
|---|---:|---:|---|---|
| 日常巩固（默认） | 80% | 40% | 余量 | 到期优先占位；到期不够时新题补，新题不超过 40% |
| 错题回炉 | 100% | 0 | 0 | 只取上次「不会」或 `hard` 的 KP；无错题则提示不出卷 |
| 单元综合 | 50% | 50% | 余量 | 覆盖优先：同课只取 1 个 KP，按课次铺开 |

**滚动比例（仅日常巩固）：** 到期题先占位后，剩余槽位按「当前单元 60%、其他旧知 40%」分配。当前单元不足时由旧知补齐，摘要写「当前单元只有 5 个可用，已用旧知补 3 题」。错题回炉、单元综合不适用此比例。

**动态含义（可直接实现）：**

- 到期可用数 ≥ 80% 槽位：到期占 80%，新 ≤20%，不排低曝光。
- 到期可用数在 40%–80%：到期全部上；新补到 40% 上限；其余低曝光。
- 到期可用数 < 40%：到期全部上；新补到 40%；其余低曝光。
- 到期为 0：新 40%，低曝光 60%。
- 任何情况下，若新知识点存在且用户选中的题型包含它，**每卷至少留 1 题给新知识点**（错题回炉除外）。

### 4.3 挑题顺序（伪代码）

```ts
function buildPaper(config, state, today) {
  const slots = sum(config.counts)
  const mode = config.mode            // 'daily' | 'review' | 'unit'
  const dueCap = mode === 'unit'   ? ceil(slots * 0.5)
               : mode === 'review' ? slots
               : ceil(slots * 0.8)
  const newCap = mode === 'unit'   ? ceil(slots * 0.5)
               : mode === 'review' ? 0
               : ceil(slots * 0.4)

  const used = { due: 0, new: 0, low: 0, early: 0 }
  const paper = []
  const shortage = []

  for (const type of config.types) {           // 按「字词→积累→句子→阅读」顺序
    for (let i = 0; i < config.counts[type]; i++) {
      const pick = nextCandidate(type, paper, state, config, used, dueCap, newCap)
      if (!pick) { shortage.push({ type, want: config.counts[type], got: i }); break }
      paper.push(pick)
      used[pick.bucket]++
    }
  }

  // 到期知识点所在题型没被选中时，只提示，不自动加题
  const starved = findDueKpsOutside(config.types, state, today)
  return { paper, shortage, starved, summary: summarize(paper, config, state) }
}

function nextCandidate(type, paper, state, config, used, dueCap, newCap) {
  const pool = candidatesFor(type, config, state)

  // 硬约束：同卷 kpId / contentKey 唯一；同词的字考点每卷最多 1 个
  // 软约束：repeatKey（素材ID+考点标签）7 天冷却；surfaceId 最近 3 卷不重复；
  //         最近 2 卷内同一 KP 必须换考点标签
  const ok = pool.filter(c => passesPaperConstraints(c, paper)
                            && passesCooldown(c, state, today, config.cooldownDays)
                            && passesSurfaceWindow(c, state, config))

  if (used.due < dueCap) { const c = takeWeighted(ok, 'due'); if (c) return c }
  if (used.new < newCap) { const c = takeWeighted(ok, 'new'); if (c) return c }
  { const c = takeWeighted(ok, 'low'); if (c) return c }
  { const c = takeWeighted(ok, 'due'); if (c) return c }   // 放开到期上限
  if (used.new < newCap) { const c = takeWeighted(ok, 'new'); if (c) return c }
  { const c = takeWeighted(ok, 'early'); if (c) return c }
  return relaxAndRetry(candidatesFor(type), ...)  // §4.6 放宽阶梯
}
```

**配额决定「取哪类池、取几个」，权重决定「池内取哪个」，两件事分开。** `takeWeighted` 见 §4.7；它不会跨池抢配额，也不会突破同卷去重与冷却。

**阅读特殊处理：** 先选「篇」，再把该篇的小题作为题组一次性排入；篇的窗口按 8 份卷（每周 1 篇）。不要出现「同一篇选 2 道题、另一篇选 2 道题」的散点选法。

### 4.4 同 KP 换考点标签的具体做法

到期 KP 进入卷面时，按以下顺序选考点标签：

1. 与 `lastVariant` 不同；
2. 该考点标签下的素材不在 7 天冷却期；
3. 若都不可用，按放宽阶梯降级；
4. 新 KP 优先用「与上次不同、且难度匹配」的考点标签；从未出现过的 KP 不受此限。

例：词「洁白」到期，上次考「看拼音」，这次优先「词语搭配」或「近反义」；若这两类未入库，则只能回到看拼音，并在摘要标「同素材同考点复现（素材不足）」。

### 4.5 用户覆盖与库存不足

**用户意图优先的部分：**

- 用户指定题型、题量、难度，覆盖预设与配比。
- 用户关闭「变式」时，允许同 KP 同卷出现 2 次（仅限不同考点标签），界面必须显示「已开启同知识点多考点」。
- 用户坚持题量超过时长，只警告，不自动截断（§6.3）。

**用户意图不能覆盖的部分：**

- 同卷 `contentKey` 唯一（除非开启上面的例外）。
- 一张卷内同一篇阅读只出现 1 次。
- 库存为 0 的题型不能被静默替换。

**例：用户要「看拼音写词语 20 题」，到期知识点不够 20 个。**

当前可出：12 个词（第一单元），第二单元 0；到期可能只有 3–5 个。处理顺序：

1. 到期词全上（假设 4 个）。
2. 用新词补到 8 个（12 个词里剩下的）。
3. 只剩 12 题，**不足 20**。
4. 摘要提示：`看拼音写词语：需要 20 题，可出 12 题（到期 4 / 新 8）。原因：已核实词语 12 个，每题面只能用 1 次。`
5. 给三个选项：
   - **减到 12 题**（推荐；总时长自动重算）；
   - **拆成两卷**（6 + 6，分别排今天/明天；明天可重复今天的词，因为隔了 1 天，冷却降到 L2）；
   - **换题型补足**（如加古诗补全或句子题），需用户手选。
6. **不能靠「同知识点多考点」凑数**：这 20 题全是 `word.kanpinyin` 同一个考点，同词换不了考点，L3 无效；要凑 20 只能允许原题面复现（L4），本方案不推荐。绝不静默出 12 题、界面仍显示 20。

### 4.6 放宽阶梯（必须按顺序，且必须告知）

| 级别 | 放宽内容 | 触发 | 摘要文案 |
|---|---|---|---|
| L0 | 全约束（7 天冷却 + 题面 3 份卷窗口） | 默认 | — |
| L1 | 冷却 7 天 → 3 天 | 某题型候选不足 | 「同素材同考点冷却已缩短到 3 天」 |
| L2 | 冷却 1 天 + 题面窗口降为「同日不重复」 | 仍不足 | 「同素材同考点只保证同日不重复」 |
| L3 | 允许同 KP 同卷出现 2 次（不同考点标签） | 用户勾选 | 「同一知识点出现 2 次」 |
| L4 | 允许原题面复现 | 用户勾选 | 「原题复现：xxx」 |

L3/L4 **不允许自动发生**，必须用户在摘要里看到并确认。L1/L2 可以自动，但摘要必须写明；**冷却期不得降为 0**（同一卷内仍禁止同素材同考点）。

### 4.7 配额之后的权重抽样（代替纯随机）

纯随机会造成同类考点扎堆（连续 3 道形近字、阅读全是概括题、病句全是同一类）。做法：**先由 §4.2 的配额决定「取哪类池、取几个」，再在池内按权重不放回抽样。**

```
w = base × urgency × error × exposure × variety
```

| 因子 | 取值 |
|---|---|
| `base` | 到期 3.0 / 低曝光 1.5 / 新 1.0 / 提前 0.5 |
| `urgency`（仅到期） | `1 + min(逾期天数, 14) / 7` |
| `error` | 上次「不会」×1.5；`hard` ×1.2（可叠乘） |
| `exposure` | `1 / (1 + 0.3 × exposures)` |
| `variety` | 卷内已出现同 `clusterKey` → ×0.2；同 `kpKind` 已达 2 题 → ×0.5 |

**`clusterKey` 定义：** 句式取「具体考点家族」（如 `pattern.gaibing:搭配不当`），阅读取「方法点」（如 `reading.short:概括`），字词/古诗取 `typeId`（如看拼音、注音）。这样「看拼音 6 题」不会被当成扎堆，而「病句-搭配不当 3 题」会被压下去。

规则：

- 权重只在同一类池内比较，**不跨池抢配额**。
- 抽样用固定种子的伪随机（如 `mulberry32(seed = paperId)`），同一份卷可复现，测试可断言。
- 同权重并列时按 KP 的稳定排序输出，保证结果不随运行环境变化。
- 任何权重都不能突破同卷去重、7 天冷却、题量上限与时长上限。
- **窄考点硬上限**：单卷同一 `clusterKey` 最多 2 题；仅对句式家族、阅读方法点、形近字、多音字生效；看拼音、注音这类题型级宽考点不受此限（否则预设直接跑不起来）。
- 阅读题组例外：一篇短文的 3–5 题算 1 个题组，不受「同 clusterKey 最多 2 题」限制。

### 4.8 到期题型的「饿死」提示

如果用户只选「古诗积累」，而看拼音/注音有 15 个到期 KP，本次不出它们。规则：

- 不自动加题型；
- 摘要下方显示一行：`另有 15 个到期知识点不在本次题型内：看拼音 5、注音 10`；
- 提供「加进本卷」按钮（按到期顺序加题，重新计算时长）；
- 若连续 3 份卷都没排进，升级为提醒：`有 15 个到期知识点已滞留 3 次，建议下次优先安排`。

## 5. 复习调度算法

### 5.1 状态字段（记在 KP 上）

```ts
export interface KpState {
  stage: number          // 0–5，对应节点：当天/次日/第3天/第7天/第14天/第30天
  mastery: 0 | 1 | 2     // 0 未掌握 / 1 一次通过 / 2 连续两次不同考点标签通过
  streak: number         // 连续「会」次数
  exposures: number      // 出现次数
  firstSeen: string      // 首次出现日期 YYYY-MM-DD
  lastDate: string
  lastPaper: number
  dueDate: string
  lastResult: 'yes' | 'no' | 'skip' | null
  lastVariant: string | null
  hard: boolean          // 难字/错字标记
  retired: boolean
}

/** 跨卷冷却日志：repeatKey（素材ID|考点标签）→ 最近一次出现 */
export interface RepeatLog {
  [repeatKey: string]: { lastDate: string; lastPaper: number }
}
```

**冷却与掌握度分开存：** KP 状态记录「什么时候该复习、会不会」；`RepeatLog` 记录「哪条素材的哪个考点最近什么时候考过」。不能用 KP 的 `lastDate` 做冷却，因为一个 KP（如「坡」）下面有多个素材和考点，各自的冷却时间不同。

### 5.2 节点制间隔（【已定】前段有依据，14/30 天为工程扩展）

| stage | 节点 | 距首次出现（天） | 说明 |
|---:|---|---:|---|
| 0 | 当天（首次出现） | 0 | 新知识点；当天在学校已学，家庭端次日复现 |
| 1 | 次日 | 1 | 徐轶「遗忘最快的前几天每天巩固」 |
| 2 | 第 3 天 | 3 | 同上 |
| 3 | 第 7 天 | 7 | 徐轶「间隔一周」 |
| 4 | 第 14 天 | 14 | 工程扩展 |
| 5 | 第 30 天 | 30 | 工程扩展；通过后退役 |

**间隔表是常量，可整体调整**（如低年级用 1/2/4/7/14）；v1 不开放家长逐项改，避免把 30 天改成 3 天造成过练。

**计算规则：**

- 新 KP 首次出现：`stage=0`，`dueDate = 今天 + 1`。
- 答「会」：`stage+1`（记作 newStage）；`dueDate = firstSeen + NODE_DAYS[newStage]`；若该日期已过，继续推进 stage 到第一个未来节点；若已超过 30 天节点，退役。
- 答「不会」：`stage=1`，`dueDate = 今天 + 1`，`hard=true`，`streak=0`，`mastery-1`。
- 留空/未看：`dueDate = 今天 + 1`，stage 不变，不算对也不算错。
- 退役：`streak ≥ 2` 且 `今天 - firstSeen ≥ 7`；退役后只作为「低曝光兜底」，不再进到期池。
- 连续 2 次「会」：升档并检查退役；连续 2 次「不会」：降到 stage 1，进「本周难字」池，单卷占比 ≤30%。
- 同一天出第二份卷：同一 KP 当天已答过的，不再重复计分；题面窗口也会挡住它。

**冷却与复习节点相互独立：**

- `dueDate` 决定「该复习了」，`repeatKey` 的 7 天冷却决定「这条素材的这个考点能不能再出」。
- 到期但冷却未过：顺延到冷却结束，不改变 stage；摘要写「N 个到期知识点因冷却顺延」。
- 冷却已过但未到期：不进到期池；只有题量不够时才作为「提前复习」兜底。
- 同一 KP 的不同素材/考点各自冷却，不互相影响（「坡」的注音 7 天内不出，不代表「坡」的形近字也不能出）。

### 5.3 状态转移表

| 当前 | 反馈 | 新 stage | 新 dueDate | mastery | hard |
|---|---|---|---|---|---|
| 任意 | 会 | `stage+1`（上限 5） | `firstSeen + NODE_DAYS[newStage]` | +1（上限 2） | 保持 |
| 任意 | 不会 | 1 | 今天 +1 | -1（下限 0） | true |
| 任意 | 留空 | 不变 | 今天 +1 | 不变 | 不变 |
| stage 5 | 会 | 5 | — | 2 | 保持；退役 |
| `streak≥2` 且跨度 ≥7 天 | 会 | — | — | 2 | 退役 |

### 5.4 只对错题与难字加密

- 「不会」的 KP 立即 `hard=true`、次日复现；连续 2 次不会时，锁定在 stage 1，并进入「本周错字」列表。
- `hard` KP 在到期池排序中优先，但**单卷占比不超过 30%**（避免一次卷全是错字，孩子挫败）。
- `hard` 在连续 2 次「会」后清除。
- 新 KP 不因「难字」标签被提前抽到；难字只影响复习优先级，不影响新知识顺序。

### 5.5 家长反馈：最小成本的三选一

**答案页：** 默认对孩子隐藏，家长可见；不显示分数、红叉数量、排名。

**每题一个三选一：** `会` / `不会` / 留空（未看）。交互规则：

- 默认模式「只标不会」：整卷默认全部为「会」，家长只需点错题；卷末点一次「已核对，全对」即可。
- 错题数 n：点 n 次 + 卷末确认。
- 一题不看：留空；整卷不看：不点「已核对」，系统判为未反馈。
- 不做「批改」「打分」「讲题」入口；只记录「会/不会」与错字。
- 面批题（扩写/仿写/阅读简答）：只勾评分点「达标 / 待改」，不换算成分数。

**成本上限：** 全对 1 次点击；3 道错 4 次点击；不核对 0 次点击（进入退化模式）。

### 5.6 家长完全不反馈时的退化

| 条件 | 行为 |
|---|---|
| 单份卷 0 个反馈 | 标记 `reviewed=false`；曝光 +1；stage 不变；`dueDate = 今天 + RETRY_DAYS[stage]`（1/3/7/14/30/30） |
| 连续 2 份卷未反馈 | 进入 `rotate` 模式：停用到期优先与掌握度，按「曝光次数升序 → 上次日期升序」轮转；新增上限降到 30%；不自动退役 |
| rotate 模式下第一次收到反馈 | 退出 rotate；stage 不补偿，从当前节点继续 |
| 长期 rotate（≥10 份） | 摘要提示「已按复习节奏轮转，建议抽一次核对，否则无法识别错字」 |

**退化后的保证：** 仍遵守同卷去重、7 天冷却、题面窗口、时长上限；只是不再声称「到期/掌握」，改为「按曝光轮转」。界面文案不写「已掌握」，只写「已出现 N 次」。

### 5.7 存储与容错

- 新增独立文件 `.quizlab/chinese-practice.json`；应用内用 localStorage 键 `quizlab.chinese-practice`。
- 不复用数学的 `gen-memory.json`：数学是「题面避重」，语文是「知识点掌握度」，语义不同。
- 结构损坏、超限、字段缺失时：备份为 `chinese-practice.corrupt-<时间戳>.json`，重建空状态，界面一句家长可读提示（沿用数学记忆的容错口径）。
- 容量：约 127 个 KP × 10 字段 + 最近 30 份卷的题面记录 + 90 天内的 `repeatLog`，预计 < 100 KB。超过 90 天的冷却记录自动清理（冷却只有 7 天，不需要永久保留）。
- 日期用本地 `YYYY-MM-DD`；一天内两份卷按 `paperIndex` 区分，但同 KP 不重复计分。

## 6. 用时控制

### 6.1 单题用时估算表

| 题型 | 分钟/题 | 依据 |
|---|---:|---|
| 看拼音写词语 | 0.6 | 2–4 字书写 + 拼音认读 |
| 给加点字注音 | 0.4 | 单字/语境词拼音 |
| 多音字组词 | 0.8 | 选音 + 组词 |
| 形近字/同音字组词 | 0.8 | 辨析 + 组词 |
| 词语搭配 | 0.5 | 选词填空 |
| 近反义 | 0.4 | 词对匹配 |
| 课文原句填空 | 0.7 | 回忆 + 书写 |
| 古诗补全（半句） | 0.8 | 5–7 字书写 |
| 古诗默写（一行） | 2.5 | 14 字左右书写 |
| 修改病句 | 1.2 | 读句 + 改一处 |
| 关联词填空 | 1.0 | 判断关系 + 填词 |
| 标点 | 1.0 | 读句 + 填标点 |
| 扩写 | 2.0 | 写 1–2 句 |
| 仿写 | 2.5 | 想喻体 + 写句 |
| 阅读（整篇开销） | 4.0 | 300–350 字短文通读 |
| 阅读选择 / 填空 / 简答 | 1.0 / 1.2 / 2.5 | 回原文定位；简答写 2–3 点 |
| 习作 | 25.0 | 250 字左右，独立包 |
| 固定开销 | 2.0 | 读卷首、写名字、翻页 |

### 6.2 公式与上限

```
预计分钟 = 2 + Σ(题量 × 单题用时) + 4 × 阅读篇数
```

- 默认目标 15 分钟；日常上限 20；诊断 30；错题回炉 5。
- 每题型上限 = `min(库存可出数, floor((目标时长 - 2 - 4×阅读篇数) / 单题用时))`。
- 题目总数上限：日常 40 题；诊断 40 题；错题回炉 8 题。
- 摘要显示「约 N 分钟」，不向下取整到 5 的倍数（数学的 5 分钟取整不适合 15 分钟档）。

### 6.3 用户题量超出时长

默认只警告、不截断，给出三个明确动作：

| 选项 | 行为 | 适用 |
|---|---|---|
| **按时长减量**（推荐） | 按「新知识点 → 低曝光 → 提前复习 → 到期」顺序砍题，到期/错题最后砍；每题型至少留 1 题 | 超时 ≤5 分钟 |
| **拆成两卷** | 生成上/下半卷，每卷 ≤ 目标时长；下半卷默认定在次日 | 超时 >5 分钟 |
| **仍按此生成** | 保留全部题量，摘要标「预计 26 分钟（目标 15）」 | 家长明确知道今天作业少 |

**绝不**在用户不知情时静默砍题；也绝不把「到期题」优先砍掉，因为到期优先是本方案的核心。

## 7. 边界情况

### 7.1 习作不进日常卷

- 语文主界面新增独立入口「单元习作」，与「生成练习卷」并列；日常选卷中 `writing` 题型置灰，原因写「习作按单元独立安排」。
- 8 个习作包对应 8 个单元（XZ-01～XZ-08），每 2 周提醒 1 次；一学期 8 次，符合课标 16 次/学年。
- 包内流程：**写（25–30 分钟）→ 评（家长按 4 行观察清单勾达标/待改）→ 改（重点段重写）**，可分两次完成。
- 家庭端**不打总分**：数据里的 30 分评分标准保留给卷面/学校口径，产品只记录「内容/条理/语言/标点书写」四项的达标状态。
- 习作包不进入选卷算法，不参与 KP 掌握度；只记录 `未写 / 已写 / 已改` 三态与更新时间。

### 7.2 课内阅读缺素材

- 「课内阅读」题型可出数 0，添加题型时置灰，原因「教材原文未入库（0 篇）」。
- 单元综合默认**跳过并提示**：摘要写「课内阅读：缺素材，本卷不含」，卷面不出现该板块，也不偷偷塞一篇课外阅读。
- 用户可显式选择「用 1 篇课外阅读替代」；替代时摘要写「课内阅读 → 课外阅读（替代）」，试卷标题同步改为「课外阅读」，并在卷面注明替代关系。
- 不把「课内阅读缺失」算作题量缺口去自动补字词；补不补由用户决定。

### 7.3 不自动判分的题如何统计

| 题型 | 记录方式 | 是否进正确率 | 展示 |
|---|---|---|---|
| 扩写、仿写 | 4 条评分点逐条勾「达标/待改」 | **否** | 「面批：3 题，达标 1 / 待改 2」 |
| 阅读简答 | 2–3 条评分点 | **否** | 计入「阅读面批」；阅读篇的掌握度只用选择/填空 |
| 习作 | 4 项观察 | **否** | 「未写 / 已写 / 已改」 |
| 病句成分残缺 10 条 | 评分点面批 | **否** | 单独列为「开放病句」 |

**正确率口径：**

- v1：`核对正确率 = 会 / (会 + 不会)`，只统计 `autoJudge=true` 且已反馈的题；留空不计入分母，面批题不计入。
- 若整卷未反馈：显示「未核对」，不显示 0%。
- 面批题单独显示「完成 n 题 / 待改 m 题」，不折算百分比，不出「总分」。

### 7.4 题库不足时的提示

统一格式（生成前摘要内）：

```
看拼音写词语：需要 8 题，可出 5 题（差 3）
原因：已核实词语 12 个；其中 7 个在最近 2 份卷出现过（窗口 3）
可选：减到 5 题 / 放宽窗口到 2 / 换其他题型
```

**原因分类（必须可区分）：**

| 原因 | 提示 |
|---|---|
| 素材未入库 | 「该题型素材为 0，需先补数据」 |
| 单元无覆盖 | 「第三单元字词未入库，暂不能出题」 |
| 冷却/题面窗口挡住 | 「最近 7 天内已考过，候选不足」 |
| 难度档不足 | 「C 档只有 6 题可出」 |
| 时长上限 | 「15 分钟最多排 21 题」 |

**禁止：** 把「课内阅读」静默换成「课外阅读」、把「看拼音」不足静默换成「注音」、把 C 档不足静默降到 A 档。

### 7.5 其它例外清单

| 场景 | 规则 |
|---|---|
| 整首古诗默写 | 按 1 题计时，占 2 个行 KP；两行算两个知识点，不违反同卷唯一 |
| 阅读题组 | 一篇 3–5 题允许同卷；篇每 8 份卷最多 1 次 |
| 同词拆字 | 同一词的「字」考点每卷最多 1 个 |
| 同一天第二份卷 | 题面窗口按「份」计算，不按自然日；同一 KP 当天不重复计分 |
| 单元综合遇空单元 | 直接提示「该单元暂无字词素材」，不生成只剩习作的假诊断卷 |

### 7.6 每题绑定课文出处

- **数据层**：KP 已有 `lessonId`；题面生成时带上 `sourceLesson`（课次 + 课文名）。字/词/诗句/习作能绑；句式与阅读是通用素材，`lessonId` 留空，不硬编「第 X 课」。
- **卷面**：每题右上角一行小字 `第 1 课《大青树下的小学》`；阅读篇只标主题（如「自然」），不标课次；句子题不标出处。
- **答案页**：重复同一条出处，方便家长对齐学校进度；不额外加「本课重点」之类解释，避免把练习册做成教辅。
- **摘要**：范围区显示「当前单元：第二单元（第 4–7 课）」，不逐题列课文，避免摘要过长。
- **未来**：若句式/阅读补了 `unitIds`，再显示出处；没有就留空，不用「全册」占位。

## 8. 生成前的呈现

用户点「生成练习卷」之前，左栏底部固定显示摘要（沿用数学的 `summary` 位置，内容加 3 行）：

**第一行（时长）：** `目标 15 分钟 · 预计 10 分钟`（超出目标时变橙：`预计 22 分钟 · 超出 7 分钟`）。

**第二行（模式与难度）：** `日常巩固 · 标准（A 11 / B 4 / C 1）`。

**第三行（题型构成）：** 逐题型一行，含题量与复习/新拆分：

```
看拼音写词语   6 题（复习 4 / 新 2）
给加点字注音   10 题（复习 7 / 新 3）
```

（示例为 16 题字词卷；混合卷会把古诗、病句、标点各列一行。）

**第四行（知识点覆盖）：** `覆盖 16 个知识点（词 6 / 字 10）`。

**第五行（新复比例）：** `新 5 : 复习 11（31% : 69%）· 到期 9 个，含错字 2 个`。

**第六行（面批与不可用）：**

```
需面批 0 题（不计入正确率）
课内阅读：缺素材，本卷不含
第三单元字词未入库，未纳入
```

**第七行（滚动比例，仅日常巩固）：** `剩余 7 题：当前单元 4 / 旧知 3（57% : 43%，目标 60 : 40）；到期 9 题另计`；当前单元不足时改为 `剩余 7 题：当前单元 5 / 旧知 2（71% : 29%，当前单元可用已到上限）`。

**卷面出处：** 每道字/词/诗句/习作题右上角带 `第 X 课《课名》`；句子题、阅读篇不标课次。摘要只显示当前单元，不逐题列出处。

**按钮：** 主按钮「生成练习卷」；次按钮「调整」；下方小字「答案页默认给家长，孩子端隐藏」。

**摘要与卷面必须一致：** 生成后卷面的题数、题型、阅读篇数、面批题数必须与摘要完全相同；不允许摘要 16 题、实际 12 题。若生成阶段才发现不足，回到摘要并提示，不直接出残卷。

## 9. 落地顺序与验收

### 9.1 阶段表

| 阶段 | 内容 | 是否必须先做 | 依赖 |
|---|---|---|---|
| **S0 知识点索引** | `knowledge.ts`：从现有 verified 数据派生 127 个 KP、考点标签、题面；`chineseAvailability()` 替代 `availableTypes` | **是**（算法前提） | 无 |
| **S1 素材补口** | 12 词拼音；49 字语境词（≥2/字）；形近字 ≥30 组；多音字 ≥10 条；阅读 97 题方法点 | **是**（字词预设前提） | S0 |
| **S2 调度器** | `chineseSchedule.ts`：节点制、会/不会/留空、退役、难字、无反馈退化 | **是** | S0 |
| **S3 选卷器** | `chineseBuilder.ts`：配额、同卷/跨卷约束、7 天冷却、权重抽样、放宽阶梯、缺口提示 | **是** | S0–S2 |
| **S4 配置界面** | 真实 `ChinesePanel`：七维度、3 模式 + 6 预设、题型可出数、摘要 | 否（可在 S3 后） | S3 |
| **S5 反馈闭环** | 三选一反馈、正确率、面批记录、持久化与容错 | 否（但决定调度是否有效） | S2、S4 |
| **S6 习作包** | 8 个单元包、三态、观察清单 | 否 | S4 |
| **S7 题库扩容** | 第 5–26 课字词、课内阅读 8–10 篇、错别字/字义/选词/成语/名言；**每篇阅读补到 8–10 题** | 否（提升容量与卷型） | S1 |

**顺序理由：** S0/S1 不完成，调度器只能拿脚本里的 12 条硬编码词跑；S2 可以先用手写假数据做纯函数测试，不必等 UI；S5 不做，调度永远停在「按时间轮转」，无法识别错字。

### 9.2 各阶段验收标准

**S0：**

- `node --test tests/chinese-knowledge.test.ts` 全绿。
- 报告输出：KP 总数 127（字 49 / 词 12 / 诗句 12 / 句式 22 / 阅读 24 / 习作 8）。
- 每条 KP 有 `kpId`、`contentKey`、`unitIds`、`level`；无 `pending` 条目进入索引。
- 可用性报告：第三～六、八单元字词为 0，第七单元只有古诗；`availableTypes` 不再被 UI 消费。

**S1：**

- 12/12 词语有拼音；49/49 字至少 2 个语境词；形近 ≥30 组；多音 ≥10 条；97/97 阅读题有 `skill`。
- 「字词巩固」目标态 23 题可出，无单字注音进入日常模式。
- 测试覆盖：词语拼音非空、语境词含目标字、形近组答案集 ≥2、阅读 skill 枚举合法。

**S2：**

- 30 天模拟：新 KP 在 D+1、D+3、D+7、D+14、D+30 依次到期。
- 「不会」→ stage 1、次日到期、hard=true；连续 2 次会且跨度 ≥7 天 → 退役。
- 连续 2 份未反馈 → rotate；收到反馈 → 退出 rotate。
- 同日两份卷不重复计分。

**S3：**

- 同一份卷无重复 `kpId` / `contentKey`；阅读题组例外只出现 1 篇。
- 同素材同考点 7 天内不复现；同素材换考点可复现；不足时按 L1→L2 缩短冷却到 1 天，L3/L4 必须用户确认。
- 题面兜底窗口 3 份卷（阅读 8 份）；L2 时降为「同日不重复」；同日两份卷不能绕过冷却。
- 配额偏差 ≤1 题；到期优先；日常巩固当前单元 60/40 偏差 ≤1 题；错题回炉 100% 到期。
- 权重抽样可复现（同 `paperId` 同结果）；窄考点（句式家族/阅读方法点/形近/多音）单卷 ≤2 题，看拼音/注音不受此限。
- 缺口提示包含「需要/可出/原因/三个选项」，且选项文案可区分。
- 生成结果与摘要一致（题数、题型、阅读篇数、面批数、当前单元/旧知比例）。

**S4：**

- 七维度默认值生效；3 模式 + 6 预设卡片显示题量与预计用时；选中不可用题型时置灰并显示原因。
- 摘要 7 行齐全；超时显示橙色；点击生成后卷面与摘要一致。

**S5：**

- 三选一反馈写入状态；全对 1 次点击；整卷不核对 → unreviewed。
- 正确率只统计 `autoJudge` 且已反馈的题；面批单独展示。
- 状态文件损坏时自动备份并重建，界面一句提示；重启后状态保留。

**S6：**

- 8 个习作包齐全；三态可切换；不进入日常选卷；不打总分。

**S7：**

- 按 `题库体检` 的扩容目标验收：字词覆盖第 1–26 课；课内阅读 8–10 篇；阅读方法题覆盖词义/概括/预测；错别字/字义/选词/成语/名言各可撑 ≥5 卷。
- **阅读扩容优先「一材多问」**：24 篇从平均 4.0 题补到 8–10 题（总题量 192–240），比新写 24 篇更省；验收时每篇至少 1 道找信息、1 道概括、1 道推断/词义。

### 9.3 本轮明确不做

- 不改 `src/**`、`typst/**`、测试；不实现判分引擎；不做语文排版模板；不做云端同步/多设备。

## 10. 外部建议的取舍（豆包，2026-11）

### 10.1 采纳

| 外部建议 | 本方案怎么落 | 落点 |
|---|---|---|
| 重复判定键 = 素材ID + 考点标签，冷却 7 天 | 同素材换考点允许且推荐；同素材同考点 7 天内跳过；题面 3 份卷兜底 | §2.3、§4.1、§5.2 |
| 配额之后按权重抽样，不用纯随机 | 池内 `base × urgency × error × exposure × variety`，固定种子可复现，同 skill 单卷 ≤2 | §4.7 |
| 滚动复习 60/40 | 日常巩固默认「当前单元 60 / 旧知 40」，只作用于到期以外的槽位，可调 70/30、50/50 | §3.1、§4.2 |
| 一篇短文多问 | 24 篇从 4.0 题/篇补到 8–10 题/篇，优先于新写短文 | §1.1、§9 S7 |
| 三种模式命名 | 日常巩固 / 错题回炉 / 单元综合，共用一套 builder | §3.3 |
| 难度 70/25/5 | 巩固型经验默认，非官方标准，可调 | §3.2 |
| 每题绑定课文出处 | 字/词/诗句/习作标课次；句子/阅读不硬绑 | §2.2、§7.6 |

### 10.2 拒绝（含理由）

| 外部说法 | 为什么不采纳 |
|---|---|
| 「上海三上语文 = 沪教版」 | **事实错误**：上海三上语文是人教社统编·五四学制版（2025 秋修订）；沪教版是数学。本方案所有单元/课次按统编口径。 |
| 「三上阅读短文 80–150 字」 | **年级口径错误**：80–150 字是二年级量级；本方案题型表定 300–500 字，题库现状 313–353 字，维持不变。 |
| 「查字典（音序/部首）、陈述句改反问句是三上重点」 | **定位偏差**：音序查字法在二年级、部首查字法在二下，三上只做巩固；反问句改写一般到三下。可作少量考点，不进主线，也不单独设专项预设。 |
| 多孩子账号 / 学习档案 | 与既定「单孩子、不做档案」冲突；v1 单档，只在状态结构预留 `studentId`，不做多档切换 UI。 |
| 纯随机抽题 | 会造成同类考点扎堆；改为「配额 + 权重 + 同 skill 上限」。 |
| 用「年级平均正确率」判断掌握 | 无官方口径，会把正常遗忘误判成退步；本方案只看单题会/不会 + 到期节点，不设班级/年级对比。 |
| 把阅读篇幅按「年级平均字数」再压缩 | 三上阅读题需要完整情节/说明结构，压到 100 字会破坏文本完整性；不采纳。 |

## 11. 已定与待定

### 11.1 已定

1. 出卷方式沿用数学：**自定义题型 + 题量**，用于专项训练。
2. 重复允许，但必须是**同一批知识点换考点标签复现**，不是原卷重印。
3. 日常语文练习 **15–20 分钟**；习作移出日常卷。
4. 到期知识点优先于全新知识点；**同一份卷内同一知识点只出现一次**。
5. 家长只做核对与记录，**不批改、不打分、不排名**。
6. 题库不足必须提示，**不静默降级成别的题**。
7. 只复现错字与难字，掌握即退出轮换。
8. 本轮只写文档，不改代码。
9. **教材口径统一为人教社统编·五四学制 三年级上册（2025 秋修订）**；阅读 300–500 字；查字典/反问句只作少量考点。
10. **重复判定键 = 素材ID + 考点标签，冷却期 7 天**（默认值，可按库存调）。
11. **日常巩固默认当前单元 60 / 旧知 40；巩固型难度默认 70/25/5**（经验值，可调）。
12. **单孩子、不做学习档案**；多孩子账号不进 v1。

### 11.2 待定（附建议值）

| # | 待定项 | 建议 | 影响 |
|---|---|---|---|
| 1 | 冷却期与题面窗口 | **7 天 + 3 份卷**（阅读 8 份） | 库存不足时会频繁放宽；假期后是否顺延需确认 |
| 2 | 单卷到期 / 新增上限 | **80% / 40%** | 决定「复习为主」还是「新题为主」 |
| 3 | 第 6 个预设「错题回炉」 | **做**，5 分钟、5 题 | 需要 S5 反馈闭环先可用 |
| 4 | 形近/多音/语境词是否本轮补 | **补**（否则字词巩固只剩 6 分钟） | 决定字词预设能否成立 |
| 5 | 阅读频率 | **每周 1 篇精读**，2 篇仅周末 | 与专业依据一致 |
| 6 | 自动判分引擎 | **v1 不做**，先家长核对 | 不影响调度，影响正确率口径 |
| 7 | 单元综合含不含阅读 | **两档**：19 分钟不含 / 29 分钟含 1 篇 | 决定卷时长与库存消耗 |
| 8 | 「当前单元」如何确定 | **手选 + 默认取所选范围中编号最大的有素材单元（当前为第二单元）** | 决定 60/40 是否准确；不做日历猜测 |
| 9 | 教材后续册/修订版 | 本册按 **2025 秋修订**；后续册另立口径 | 影响 `kpId` 迁移与状态复用 |

> §10.2 已明确不做多孩子账号，不再列入待定。

## 13. 一句话给产品负责人

**这套设置的核心不是「让家长每天配题」，而是「默认就按遗忘规律出题，家长只在想专项训练时改题型和题量」；语文的重复由算法负责，原题重印由约束拦住，错字和难字由反馈记录带路。**
