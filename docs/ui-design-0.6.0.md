# 0.6.0 界面与操作逻辑设计方案

- 日期：2026-11-05
- 主题：把"能自己用"改成"能发给别的家长用"
- 配套：[体检报告](ui-review-0.6.0.md) ｜ [可交互原型](ui-prototype-0.6.0/index.html)
- 范围：只做界面与交互设计，本版不改 `src/app/*.vue`、不改版本号、不新增出题能力

---

## 1. 一句话目标与验收

**目标**：一位没用过电脑排版的家长，打开应用后不需要读任何说明，就能在 3 步内拿到一张可打印的 A4 练习卷。

**验收**：
1. 首次打开不填任何东西，也能直接出卷（默认值就能出）。
2. 出卷前能看到"几道题、约几页、大约做多久"；出卷后能看到"实际几页、存在哪"。
3. 界面上不出现英文缩写与内部机制名（typst、编译、校验、去重命中、骨架、L1/L2/L3、单元 ID）。
4. 任何失败状态都有一句家长话 + 一个可点的下一步。

## 2. 借鉴：三个成熟产品，各借什么

### 2.1 组卷网 / 学科网「智能选题」（试卷生成网站）

流程（官方帮助与介绍页）：选教材版本与考核范围 → 设置试卷条件 → 按题型填写数量（**不需要的题型不填数值**）→ 生成试卷 → 检查生成结果并加入试题篮 → 下载打印。另有"智能排版"，试卷标题、装订线、誊分栏可一键设置。

**借**：
- **"不填=不出"的行级题量**：只填想要的题型，其余留空，不需要先理解"0 表示不出"。对应我们 D1/B3 的修法。
- **生成后先给一张"整卷检查"页，再给下载/打印**：我们对应"结果卡 + 预览"，先确认页数再打印。
- **排版模板一键设置**：纸张、抬头、装订线这类"高级项"给默认值，收在设置里。

**不借**：5 步向导、试题篮、按知识点逐题挑题——那是老师的备课场景，家长只要一份当天练习。

### 2.2 小猿口算「每日一练」（教辅出题 App）

流程：练习 → 每日一练 → 年级/学期/教材版本（一次设定，之后长期复用）→ 练习范围 → 题目数量 → 打印。

**借**：
- **入口就叫"每日一练"**，家长一看就知道是每天一张，不需要理解"练习模式/整卷模式"。
- **孩子档案设一次**：年级、学期、教材版本设好就不再来回选；对应我们把"三年级上册 · 沪教版"固定在标题区。
- **题量是少量快捷选项**，不是一张 12 行的表单；对应"套餐 + 少量题型 stepper + 更多题型折叠"。
- **打印是最终唯一的大按钮**。

**不借**：拍照批改、班级、错题本等重功能；本版不做。

### 2.3 macOS 打印对话框（桌面打印）

范式：左侧一张当前页缩略图，标题写"第 1 页，共 3 页"；默认只露打印机/份数/纸张，其余收在"显示详细信息"；整屏只有一个主按钮"打印"。

**借**：
- **打印前一定先看到页数与缩略图**：对应首屏"约 2 页"，结果页"2 页"。
- **高级项默认折叠**：对应设置→高级（排版组件、运行信息）。
- **一个主按钮**：对应"打印"；"保存 PDF"降为次按钮。

**不借**：把打印机队列、驱动参数直接摊开；家长只需要"份数/双面"。

> 参考来源见文末。

## 3. 主流程：3 步

| 步骤 | 用户看到什么 | 用户做什么 | 系统做什么 |
| --- | --- | --- | --- |
| **1. 出卷** | 左栏已预填"全部单元 / 标准 / 每日一练 28 题"，右栏空态提示"点一下就能出卷" | 点大按钮"出卷"（想改就先改单元或题量） | 生成 + 排版，进度条与预计时长 |
| **2. 确认** | 结果卡："28 题 · 2 页 · 约 20 分钟"，右栏整页预览 | 翻一页看看，不满意点"换一套" | 回填实际页数、保存文件 |
| **3. 打印** | 主按钮"打印"、次按钮"保存 PDF" | 点"打印"，在系统面板选打印机/份数 | 打开系统打印面板 |

- 第一次打开到第一张纸出来，**只需要点两次**（出卷、打印），中间"确认"是看一眼，不是必填。
- "换一套"= 同参数重新出卷（现有 seed 递增即可），不增加步骤。
- 改参数后主按钮文案变"重新出卷"，出卷完成后自动回到步骤 2。

## 4. 信息架构

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部：数学每日一练 · 三年级上册 · 沪教版    [历史卷]  [设置] │
├───────────────────────────┬──────────────────────────────────┤
│ 左栏 340px（常驻）        │ 右栏（常驻）                     │
│                           │                                  │
│ 单元选择                  │ 预览工具条：第 1/2 页 · 适应宽度 │
│   [单元 chip × 7]         │ ┌──────────────────────────────┐ │
│                           │ │                              │ │
│                           │ │        A4 纸张预览           │ │
│ 题型设置                  │ │                              │ │
│   难度 [基础|标准|挑战]   │ │                              │ │
│   套餐三行：标题·说明·题量 │ │                              │ │
│   口算      [−] 20 [+]    │ │                              │ │
│   填空      [−]  5 [+]    │ └──────────────────────────────┘ │
│   应用题    [−]  3 [+]    │                                  │
│   ＋ 添加题型（弹层）     │                                  │
│                           │                                  │
│ ③ 出卷（sticky 底部）     │                                  │
│   共 28 题 · 约 2 页 ·    │                                  │
│   约 20 分钟              │                                  │
│   [        出卷        ]  │                                  │
└───────────────────────────┴──────────────────────────────────┘
```

**常驻 vs 收起**

| 区域 | 内容 | 理由 |
| --- | --- | --- |
| 常驻·顶部 | 产品名、年级+教材、历史卷、设置 | 只放"换场景"的三个入口 |
| 常驻·左栏 | ①范围 ②难度+套餐+常用题型 ③总题数与出卷 | 首屏必须能完成一次出卷 |
| 弹层·左栏 | "添加题型"（其余 9 类，分组勾选） | 低频，默认不出现；见 §5.5 |
| 弹窗·设置 | 打印（纸张/份数）、出卷偏好（默认难度/套餐/避重复）、题库（记录/清空）、数据（备份/导出导入）、高级（排版组件、运行信息） | 设置一次，长期不动 |
| 抽屉·历史卷 | 最近 10 份：日期、范围、题量、页数、[再印一份] | 需要先拍板是否做（见 §9） |
| 状态条·预览上方 | 只允许同时存在 1 条：成功/提示/警告/错误 | 解决横幅堆叠（E5） |

**页面/面板清单**：主出卷界面、结果态（同一页面的结果卡+预览）、设置弹窗、历史卷抽屉、打印前确认（交给系统面板，不自建）。

## 5. 每个界面的字段与默认值

### 5.1 主出卷界面（常驻）

| 字段 | 控件 | 首次启动默认值 | 范围 | 说明/文案 |
| --- | --- | --- | --- | --- |
| 年级与教材 | 只读文字 | 三年级上册 · 沪教版 | 固定 | 不出现下拉；无第二选项 |
| 单元 | 多选 chip（两列） | **全部 7 个单元** | 至少 1 个 | 默认全选，保证一键出卷；不显示"范围：全部 N 个单元"汇总行 |

| 题量套餐 | 3 行竖排卡 | **每日一练** | 每日一练/单元小测/周末加练 | 每行左标题、中说明、右题量；点选即写入题量；之后手动改数字，套餐卡取消高亮 |

| 填空 | stepper | 5 | 0–200 | 同上；首次只在常用区出现 |
| 应用题 | stepper | 3 | 0–200 | 同上 |
| 添加题型 | 弹层（分组勾选） | 收起 | 其余 9 类 | 每项"勾选框＋说明＋默认题量"；不能出的置灰写原因；完成后带回主界面，见 §5.5 |
| 其他题型默认值 | stepper | 竖式 6、递等式 6、简便 4、比大小 4、图形 4、判断 4、选择 4、列式 4、拓展 3 | 0–200 | 与引擎默认一致（简便例外：引擎默认 0，界面给 4） |

| 超量提示 | 行内提示 | 不显示 | >60 题且超可用量时 | 用现成 `typeCapacityHint` 文案，例："口算：目前大约能出不重复的 120 道，设到 200 道时，后一卷约有 40 道会和以前的卷子重复" |

## 5.5 题型添加与移除（A/B 两方案）

旧版把 12 个题型全部铺在左栏，未勾选的也显示题量（竖式 6、比大小 4……），和"总题数"对不上（见体检 B3/D1）。两种方案都改成**主界面只显示已选题型 + 一个添加入口**，把"挑选"收进弹层。

### 方案 A：勾选后完成（主方案）

- 主界面只列已选题型，每行紧凑：`题型名　[− 20 +]　×`。移除即从本卷去掉，不留空行。
- 唯一入口是列表下方的 `＋ 添加题型`。
- 点开后是弹层（宽 520，居中）：按 **计算题 / 填一填、选一选 / 综合应用** 三组排列。组名加粗、比题型名大一级，带折叠箭头与分隔留白，不跟题型行同级；每组可点击折叠，默认全部展开，组名后不再跟说明句。
- 每项一行：勾选框、题型名、一句人话说明（"列竖式算乘除法"）、右侧"默认 6 题"。
- **能不能出**：当前所选单元出不出的按灰色显示，行内写具体原因，例如"所选的单元里没有图形或周长的内容"；只有部分单元支持时写"只在「用一位数乘、用一位数除」单元有"。
- 底部：`已选 N 项`、`取消`、`完成`（主按钮）。
- 只有点"完成"才把勾选项带回主界面并收起；点"取消"、点弹层外部、按 Esc 都**不改动**。
- 收起后主界面保持紧凑；超出可用量的提示留在对应的已选行下方（"约能出 120 道不重复，超出的部分可能和旧卷重复"），不随面板收起而消失。

### 方案 B：标签 + 即时添加

- 已选题型做成带题量的标签：`口算 20`、`填空 5`。
- 点某个标签，下方展开一行调整区：`「口算」每份 [− 20 +] ×`；再点标签收起。
- `＋ 添加题型` 打开带**搜索框**的分组清单，输入"竖式"即可过滤。
- 点一项**立即加入**（无"完成"步骤），标签区实时变化；再点同一项则移除。
- 点外部、按 Esc 或点"关闭"退出；已加入的内容保留。

### 对比

| 维度 | 方案 A（勾选后完成） | 方案 B（标签即时添加） |
| --- | --- | --- |
| 操作步数 | 打开 → 勾选 → 完成（3 步） | 打开 → 点选（2 步） |
| 误操作风险 | 低：取消可整体放弃 | 中：点一下即改，需再点一次撤回 |
| 批量选择 | 强：一次勾 3–4 类再确认 | 弱：逐项点，边点边改 |
| 已选状态可见性 | 主界面行式，题量清楚 | 标签式更紧凑，但题量字号小 |
| 适合谁 | 第一次用、想一次配好 | 熟手、经常微调 |
| 与"超出可用量"提示 | 直接显示在对应已选行下方，最贴近 | 只在底部提示，需自己对应到题型 |

### 推荐

**0.6.0 采用方案 A。** 理由：
1. 目标读者是"别的家长"，第一次用时需要看清每组题是干什么的；A 的说明＋默认题量在一屏内可读完，B 的标签只有名字。
2. "完成"提供一次确认点，避免误点导致题量、页数瞬间变化；对不熟悉界面的家长更稳。
3. A 与设置弹窗的交互一致（勾选→确认），学习成本低。B 可作为熟练用户的快捷模式在后续版本提供。

对应截图：`screenshots/addA-open.png`、`addA-collapsed.png`、`addB-chips.png`、`addB-panel.png`。

## 9. 需要拍板的 3 个选择

1. **历史卷做不做？** 做：右上抽屉，最近 10 份，可"再印一份"；成本是新增一份本地记录 + 打开旧 PDF。不做：家长靠"保存 PDF"自己管文件。
2. **题量用 stepper 还是输入框？** stepper（推荐，适合家长、不会输错）还是数字框＋加减（紧凑但需要键盘）；或"套餐卡 + 少量 stepper + 其余题型走添加弹层"的混合（本方案默认）。
3. **设置里要不要放"答案/解题提示"开关？** 现状排版没有答案页；若放开关需新增排版能力，超出 0.6.0（建议先不放，标注"0.7.0"）；若不放，结果卡也不提答案。
