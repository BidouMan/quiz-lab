## 0. 版本冲突（必须先看）

上一轮资料里同时存在两套第三单元目录，本批**只用新版**：

| | 第三单元篇目 |
|---|---|
| 旧版（2022 前后） | 卖火柴的小女孩 / 那一定会很好 / 在牛肚子里旅行 / 一块奶酪 |
| **新版（2025 秋修订）** | **总也倒不了的老屋 / 犟龟 / 小狗学叫** |

判定依据：教师用书（2026-09 发布）目录里有《犟龟》，电子课本目录里有《宝葫芦的秘密（节选）》《一定要争气》《一个粗瓷大碗》，旧版没有这些篇目。

因此：

- 凡是只能从旧版三表回溯的字词，一律不进本数据层；本批未出现此类条目。
- 第二单元第 4 课《古诗三首》的三首篇目由新版写字表反证（寒/径/斜/枫/霜 → 《山行》；庭/相/未 → 《望洞庭》；挑/落 → 《夜书所见》），不是旧版条目。
