# L4 自命题执行规范（工作稿，不提交）

## 目标
为 `tools/reading-intake/work/l4-candidates.jsonl` 中的 49 篇素材逐篇新命 4 道题，产出可直接过质检闸门的命题稿，写入 `data/reading-catalog/quiz-drafts/RD-XXX.json`。

## 铁律
1. **正文一字不改**：直接复制候选记录里的 `paragraphs`、`title`、`theme`、`sourceId`、`sourceCharCount`、`charCount`。不要增删改正文，否则字数、引句锚点会失效。
2. **不碰其他文件**：只新建/修改分配给你的 `RD-*.json`。不要动 `quality-gate.jsonl`、`mounted.ts`、其他命题稿。
3. **不自造原文**：题干、答案、解释里的每一处引号引文，必须逐字出现在正文中（标点可不同，汉字必须连续一致）。
4. 写完必须自己跑：
   ```bash
   python3 tools/reading-intake/quality_gate.py --ids RD-502,RD-503 --dry-run
   ```
   直到分配给你的篇目全部 `pass`。R1–R12 命中任何一条都要改到通过。

## 稿件字段
按 `RD-501.json` 的格式（可直接读该文件当模板）：

```json
{
  "id": "RD-502",
  "sourceSeq": "素材 id",
  "kind": "extracurricular",
  "scope": "extracurricular",
  "term": "3A",
  "sourceId": "候选里的 sourceId",
  "title": "候选里的 title",
  "theme": "候选里的 theme",
  "status": "verified",
  "sourceCharCount": 候选里的 sourceCharCount,
  "charCount": 候选里的 charCount,
  "paragraphs": 候选里的 paragraphs,
  "sources": [{"label": "21世纪教育网 三上阅读素材《标题》", "locator": "ns21cnjy batch 素材 <sourceId>"}],
  "review": "2026-11-08 自命题。素材：…（写清洗与来源）。原卷无可用原题与答案，四题全部新命：…。客观 2∶主观 1，考点覆盖 … 4 类。难度按脚本口径：… 字、…，判为易/中/难。人工复核：…",
  "questions": [ ... 4 道 ... ]
}
```

## 四题结构（默认）
1. 选择题 `skill: "梳理概括"`：概括内容/顺序/写了哪几方面。
2. 选择题 `skill: "推断体会"`：由人物言行、结果、关键词推断原因/心理/道理。
3. 填空题 `skill: "提取信息"`：题干一个 `（ ）`，`blanks` 一个词，必须逐字在正文。
4. 简答题 `skill: "词句理解"` 或 `"主旨情感"`：赏析词句/体会情感/说明道理，`scoring` 两条。

如素材明显适合写法结构，可把第 2 题改成 `skill: "写法结构"`（此时第 1 题仍须是 `梳理概括`，R4 要求含 SK2 或 SK4，含 SK2 即可）。非连续性/材料型文本可用 `skill: "非连续性文本"`。**不要为了凑 SK 硬贴标签**。

每题都带：
```json
"score": 2,
"skill": "...",
"answerSource": "new",
"origin": {"action": "新命", "original": "（原卷无可用原题）", "note": "一句话说明考查点"}
```
简答 `score: 4`，另有 `"answer": "参考答案"`。

## 各规则怎么过
- **R3**：正好 4 题。
- **R4**：至少 3 类考点；必须有 SK2 或 SK4 中的至少一个；简答必须是 SK3/SK5（或带情感词的 SK4）。
- **R5**：客观（选择+填空）≥2，主观（简答）≥1。
- **R6**：题干不要出现 `读音/字音/字形/错别字/默写/拼音/加点字/量词/作者是/文学常识/看拼音/抄写/摘录/照抄/画出/用横线画出/原文中找出`。
- **R7**：填空 `（ ）` 数量 = `blanks` 数量；答案必须能在正文逐字找到（汉字连续）。
- **R8**：选择题 4 个选项互异；`answer` 是 0–3；`explain` 里至少有一处 `“……”` 引文 ≥6 个汉字且逐字在正文。
- **R9**：简答 `scoring` 恰好 2 条；每条至少有一处 `“……”` 引文 ≥4 个汉字且逐字在正文。语义解释可以放在引文之后，但引文本身必须是原文连续片段。
- **R10**：选项长度比 ≤2.0（最长/最短，含标点）；不要出现 `以上都对/无法判断/都不对`；同篇两个选择题的正确项不要都放同一位置到最后三题连续（本批每篇只有 2 道选择题，不会触发，但仍建议 A/B 位交替）。
- **R11**：每题必须有合法 `skill`：`提取信息`、`梳理概括`、`词句理解`、`推断体会`、`主旨情感`、`写法结构`、`非连续性文本`。
- **R12**：难度按正文字数与考点算：正文 <350 字 → 易；350–550 → 中；>550 → 难；若用了 `写法结构`/`非连续性文本`，一律记为难。写进 `review`。

## 出题质量要求（脚本判不了，必须自己把关）
- 选择题干扰项要“同质同域”：四个选项都在回答同一个问题，长度、句式接近，错项要像“学生会犯的错”，不要明显荒谬。
- 填空题不要考纯记忆；空要落在能体现理解的词上。
- 简答题要能用原文定位：评分点先给原文依据，再给理解；开放题也要有可核对的要点。
- 每题只考一个点，题干不绕。
- 不要照抄原卷题；原卷无题或题目不可用时，按上面结构自己写。
