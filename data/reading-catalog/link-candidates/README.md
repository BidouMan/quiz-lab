## 文件

- `links.txt`：可切出短文的文章链接，一行一条（按合集篇数从多到少）。
- `passages.csv`：短文级明细，字段含字数、体裁、是否带题、是否合集、合集篇数、sha256、正文前 400 字。
- `verified.jsonl`：逐条访问记录（URL/标题/账号/汉字数/结果/时间）。
- `pool.json`：候选池（含未验证/失效）。

## 口径与局限

- 字数按正文容器汉字计；切分以“短标题行 + 长段”为界，可能把长文里的过渡句当成标题，导致个别短文被切短。
- 体裁为关键词粗分（寓言/童话、科普、状物、写人、写景、写事、其他），只用于初筛排序，不是终判。
- 合集篇数取“实际切出的短文数”，与标题里写的“13篇/40篇”可能不一致；标题声明值记录在 `verified.jsonl` 的标题里。
- 同一篇短文被多个公众号转载时，只保留 sha256 首次出现。
- 链接是微信分享链（带 signature），会过期；正文已缓存，重跑时优先读缓存。
