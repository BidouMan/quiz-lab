## 题目质量复核口径

先做结构判定：正文段（题目之前的文字）≥80 字，且题目与正文二元组重合或出现「文中/第X段/画线」等定位词，否则判「脱节」。

再做题质打标（`question_quality` 列）：

| 标记 | 判定 | 一句话理由示例 |
|---|---|---|
| 可用 | 题型 ≥2 类，正文定位强 | 题型有梯度且可在正文定位 |
| 需返修 | 套话/一二年级问法/四五年级问法/考法扎堆/定位弱 | 部分题目靠常识可答，正文定位弱 |
| 剔除 | 无题目、正文 <80 字、答案无法定位 | 题目无法在正文定位 |

## 文件

- `passages.csv`：可用池 106 篇，含字数、分档、体裁、是否合集、正文段字数、定位比例、题质标记与理由、sha256
- `passages-need-pairing.csv`：172 个只有题目的片段（待与正文配对）
- `passages-dropped.csv`：真正剔除项（脱节/无题/残片），保留字段可复核
- `links.txt` / `verified.jsonl` / `pool.json`：链接与访问记录

## 说明

- 超过 600 字的长文不再切碎，按整篇计，只标实际字数。
- 172 个「待配对」来自「先列正文、后列题目」的排版：正文块与题目块被切成两段，不是素材不可用，是配对未完成。
- 题质标记是启发式（关键词+二元组重合），只能做初筛；抽查仍需人工看 5–8 篇。
