## 说明

- 合并规则：小于 250 字的块，若与相邻块的边界没有句末标点（。！？…"」），或本身不足 150 字，则并入相邻块，合并后不超过 600 字。
- 合并后重新计算字数、重新判定是否带题，并重新算 sha256 去重。
- 体裁为关键词粗分，仅作排序参考。
- 链接为分享链会过期；正文已按 URL 缓存，重跑优先读缓存。
